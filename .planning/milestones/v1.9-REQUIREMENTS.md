# Requirements Archive: SPU-94 v1.9 Complete Voice

**Archived:** 2026-05-24
**Status:** 37/37 requirements complete
**Milestone tag:** `v1.9`

## Requirements (all complete)

### ADSR Correction (Phase 33)

- [x] **ADSR-FIX-01**: Sustain-decrease step formula uses `-(8 - step)` producing steps -8, -7, -6, -5
- [x] **ADSR-FIX-02**: Release step formula audited and corrected (base 8 per spec)
- [x] **ADSR-FIX-03**: ADR-0056 documenting the correction with spec source citation
- [x] **ADSR-FIX-04**: ADSR golden files regenerated and regression suite updated

### Signed Volume (Phase 34)

- [x] **SVOL-01**: Per-voice vol_l/vol_r accepts full signed range (-0x4000..+0x3FFF)
- [x] **SVOL-02**: All call sites audited — positive-only clamping removed
- [x] **SVOL-03**: Negative volume produces phase-inverted output (exact negation)
- [x] **SVOL-04**: VxOUTX unaffected by volume sign (captured pre-volume)
- [x] **SVOL-05**: GUI exposes signed volume range with phase-flip indicator

### Pitch Modulation — PMON (Phase 35)

- [x] **PMON-01**: 24-bit bitmask register enables PMON per voice (bits 1..23; bit 0 ignored)
- [x] **PMON-02**: VxOUTX stored post-ADSR, pre-volume — used as PMON factor for next voice
- [x] **PMON-03**: Formula: Factor = VxOUTX(N-1) + 0x8000; Step = (Step * Factor) >> 15; clamp 0x4000
- [x] **PMON-04**: Silent modulator (output=0) produces Factor=0x8000, halving carrier pitch
- [x] **PMON-05**: Voice processing order 0..23 sequential, VxOUTX written immediately
- [x] **PMON-06**: Chain stacking works (0->1->2 cascading modulation)
- [x] **PMON-07**: ADR-0057 documents VxOUTX capture point with DuckStation witness

### Noise Generator — NON (Phase 36)

- [x] **NON-01**: Single global LFSR, taps 15,12,11,10 XOR 1 (XNOR), seed=1, left-shift
- [x] **NON-02**: Timer mechanism: decrement by NoiseStep per tick, shift on underflow, double-reload
- [x] **NON-03**: Frequency from SPUCNT bits 13..8; per-voice pitch has no effect on noise
- [x] **NON-04**: 24-bit NON bitmask selects which voices output noise
- [x] **NON-05**: All NON voices read same NoiseLevel per tick (one generator, not per-voice)
- [x] **NON-06**: ADPCM decode still runs for NON voices (flag side effects)
- [x] **NON-07**: ADSR envelope still applies to noise output
- [x] **NON-08**: Noise generator ticks once globally before voice loop
- [x] **NON-09**: ADR-0058 documents polynomial, seed, ADPCM-fetch-during-NON

### Volume Sweep (Phase 37)

- [x] **SWEEP-01**: Independent L/R state machines (2 sweep states per voice)
- [x] **SWEEP-02**: Linear increase/decrease, exponential increase (fake >0x6000), exponential decrease
- [x] **SWEEP-03**: Step values: increase +7,+6,+5,+4; decrease -8,-7,-6,-5
- [x] **SWEEP-04**: Counter-accumulate mechanism identical to ADSR (shared helper, separate state)
- [x] **SWEEP-05**: Sweep modifies vol_l/vol_r directly (volume register IS sweep's working state)
- [x] **SWEEP-06**: Sweep and ADSR run concurrently as independent envelopes
- [x] **SWEEP-07**: KON resets sweep state; KOFF does not affect sweep
- [x] **SWEEP-08**: Anti-stall guard (if scaled_step==0 && level>0, step=-1)
- [x] **SWEEP-09**: Negative-phase sweep operates on negative volume, clamps -0x8000..0
- [x] **SWEEP-10**: ADR-0059 documents negative-phase uncertainty

### Integration (Phase 38)

- [x] **INT-01**: Mixer tick order: noise global -> sweep -> PMON -> decode -> noise/Gauss -> ADSR -> outx -> volume -> accumulate
- [x] **INT-02**: NON+PMON: noise output feeds PMON factor for next voice (random pitch jitter)
- [x] **INT-03**: All existing features unbroken (ADSR, loops, EON, Gaussian, anti-aliasing, MIDI)
- [x] **INT-04**: rt_safety gates pass with all features enabled

### Pan & Level Controls (Phase 39)

- [x] **PAN-01**: Pan knob controls L/R balance
- [x] **PAN-02**: Level fader controls overall volume scaled by pan
- [x] **PAN-03**: Teal INV indicator visible and functional with negative volume
- [x] **PAN-04**: Pan+Level produce identical register values as old raw knobs

### Voice Feature Toggles (Phase 40)

- [x] **TOG-01**: Per-voice NON toggle enables/disables noise output
- [x] **TOG-02**: Per-voice PMON toggle enables/disables pitch modulation
- [x] **TOG-03**: NON replaces ADPCM output (ADPCM still decodes for flags)
- [x] **TOG-04**: PMON on voice N modulates by voice N-1's outx

### VCA Ramp Controls (Phase 41)

- [x] **RAMP-01**: Direction (up/down), speed, and curve controls in GUI
- [x] **RAMP-02**: Controls configure both sweep_l and sweep_r with matched params
- [x] **RAMP-03**: Speed labeled in seconds (~0.1s to ~7s)
- [x] **RAMP-04**: Activating ramp produces audible volume change
- [x] **RAMP-05**: Ramp state resets on KON

### Voice GUI Integration (Phase 42)

- [x] **VGUI-01**: All controls function with multiple features active simultaneously
- [x] **VGUI-02**: Existing sampler features unbroken
- [x] **VGUI-03**: rt_safety gates pass with all GUI-driven features enabled
