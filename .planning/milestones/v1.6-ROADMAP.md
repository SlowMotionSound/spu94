# Roadmap Snapshot: v1.6 User Programmable Waypoints

**Snapshot taken:** 2026-05-10 (at milestone ship)
**Tag:** `v1.6`
**Status:** Shipped

## Milestone Goal

Open user-programmable waypoint slots between Sony's 9 factory anchors, transparent when empty (bit-identical to v1.5) and acting as new interpolation breakpoints when filled. Surface the slots as visible tick detents on the morph knob with per-tick EDIT / EXPORT / LOAD action buttons and a SAVE/REVERT edit flow. Persist filled slots in the existing `.spu94` preset format with byte-identical back-compat for pre-feature presets.

## Phases

### Phase 18: User Slots Core
**Goal:** 8 user-programmable slots on `spu94_state` at midpoint positions between Sony's 9 anchors. Empty = transparent. Filled = new interpolation waypoint with INTERP-04 bit-identity carve-out.
**Requirements:** USLOT-01..06
**Files:** `src/spu94/spu94_interp.c`, `include/spu94/spu94.h`, `tests/unit/interp/test_user_slots.c`
**Status:** Complete

### Phase 19: Waypoint GUI
**Goal:** Surface user slots as 17-detent knob ticks; per-tick EDIT/EXPORT/LOAD action stack; SAVE/REVERT edit flow; engine state mirroring overhaul.
**Depends on:** Phase 18
**Requirements:** USLOT-07..14
**Plans:** 2 (19-01 ticks + snap, 19-02 edit flow + per-tick actions)
**Files:** `juce-plugin/Source/MorphPanel.{h,cpp}`, `juce-plugin/Source/PluginEditor.{h,cpp}`, `juce-plugin/Source/PluginProcessor.{h,cpp}`, plus C-core single-slot file I/O additions in `src/spu94/spu94_interp.c`
**Status:** Complete

### Phase 20: User Slot Persistence
**Goal:** Filled user slots survive save/load through `.spu94` preset format. Empty slots omitted (byte-identical back-compat with pre-feature presets).
**Depends on:** Phase 18
**Requirements:** USLOT-15..17
**Files:** `src/spu94/spu94_preset.c`, `include/spu94/spu94.h`, `tests/unit/preset/test_preset.c`
**Status:** Complete

Two pre-existing files in this directory — `v1.6-ROADMAP-archived.md`, `v1.6-STATE-archived.md`, `v1.6-HANDOFF-archived.json` — are from an earlier abandoned v1.6 attempt (Macro Controls) that was pivoted away from in favour of the v1.5 Preset Interpolation Engine approach.
