Add a VCA Ramp control section to the sampler GUI that exposes the C core volume sweep as a musician-friendly fade in / fade out with speed (in seconds) and curve (Linear / Natural) controls, plus an Arm button to trigger the ramp.

Output: VCA Ramp section in sampler window with direction toggle, speed knob, curve toggle, and arm button. Processor atomics wired to sweep API calls on the audio thread.

typedef struct {
    int16_t  level;       /* current sweep level (IS the volume) */

| T-41-02 | Tampering | rampSpeed atomic float | accept | Clamped by speed-to-shift mapping (nearest match within shift 9-17 table). Out-of-range floats produce edge values. |
| T-41-03 | Denial of Service | set_sweep_l/r called on ARM | accept | One-shot via atomic exchange (rampArm reset to false). Cannot be triggered faster than processBlock rate. Each call is O(1). |
