<objective>
Fix the PS1 ADSR envelope sustain-decrease and release step formulas to match the nocash
psx-spx specification. The current code uses base 7 (producing steps -7,-6,-5,-4 for
sustain-decrease and -7 for release), but the spec uses base 8 (producing -8,-7,-6,-5
and -8 respectively). This off-by-one makes sustain decay and release slightly slower
than real PS1 hardware.

Purpose: Correct the ADSR before Phase 37 (Volume Sweep) reuses the same decrease
formula. Fixing now prevents the bug from propagating into sweep.

Output: Corrected spu94_adsr.c, updated test_adsr.c with regression coverage for
the exact step magnitudes, and ADR-0056 documenting the correction.
</objective>

    ADR-0056 title: "ADSR sustain-decrease and release off-by-one correction"

    Status: Accepted, Date: today (2026-05-22), Phase: 33 (ADSR Correction),
    Requirement: ADSR-FIX-01, ADSR-FIX-02

    Context section: The v1.8 ADSR implementation used base 7 for decrease formulas
    (sustain-decrease: 7-step, release: 7-0=7). This produced steps of -7,-6,-5,-4
    for sustain and -7 for release. The nocash psx-spx specification states the
    decrease formula uses base 8, matching the decay phase which already used -8 correctly.
    The error made sustain decay and release approximately 12.5% slower than real PS1 hardware.

    Decision section: Changed both decrease formulas to use base 8:
    sustain-decrease step = -(8 - step) producing -8,-7,-6,-5 for step values 0..3;
    release step = -(8 - 0) = -8. This aligns sustain-decrease and release with the
    decay phase (which already used -8) and with the nocash spec. Attack and
    sustain-increase continue to use base 7 (the increase formula is correctly
    (7-step) per spec).

    Consequences section: Sustain decay is approximately 12.5% faster, matching
    hardware. Release is approximately 14% faster. Golden regression tests updated
    to assert the corrected magnitudes. Volume Sweep (Phase 37) will reuse the
    same -(8-step) pattern for its decrease path.

    Sources section: Reference nocash psx-spx "SPU ADSR Generator" section,
    specifically the AdsrStep table for decrease modes.
  </action>
