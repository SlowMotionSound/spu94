## Resolved Gaps Log

### 1. Phase 6 Missing VERIFICATION.md → CLOSED

Phase 6 (Python Binding + CLI) ships `06-VERIFICATION.md` as of 2026-04-25 (Step 14, commit fddbcad). Verifies all 4 ROADMAP success criteria + 11 declared requirements (PYBIND-01..06, CLI-01..04, DOCS-04) in the established gsd-verifier shape (artifact-level + link-level + behavioral-spot-check evidence). The 11 Phase 6 requirements are now 3-source verified (VERIFICATION + SUMMARY + traceability), promoted from the prior 2-source (SUMMARY + UAT only).

### 2. Python `work_buf_size` Default Undersized → CLOSED

`SPU94()` and `api.init()` default to `work_buf_size=SPU94_WORK_BUF_MAX_BYTES` (512 KiB) as of 2026-04-24 (Step 5, commit fdeeb57). The pre-remediation 8192-byte default forced every Hall-or-larger caller to either trip silent degradation (pre-Step-3) or `SPU94_WORK_BUF_TOO_SMALL` (post-Step-3). Embedded callers can still pass a smaller value explicitly; ADR-0022's work-buf contract (Step 3, commit 72f2270) ensures undersized buffers are rejected at load_preset time rather than producing acoustically-degraded output. ADR-0023's `oob_tap_count` observable (Step 4, commit bce2c13) plus the Step 6 assertion floor (commit efdf9a5) provide a runtime regression gate against any future hand-configured-undersized-buffer scenario.

### 3. Modulation Harness Ran on Degraded Reverb → CLOSED

`tests/python/modulation_harness.py` historically ran with the 8192-byte work_buf default — every Hall modulation case was silently under-buffered. Step 6 (commit efdf9a5) adds an `oob_tap_count == 0` assertion across all 105 (reg × mode) cases; the Step 6 regen of `tests/python/modulation_report.json` (committed separately as ce8385e) reflects the post-fix baseline with `oob_tap_count: 0` everywhere. The modulation catalog at `docs/LEVERS-CATALOG.md` was generated from this corrected reverb output.

### 4. Witness-Diff Measurement-Only → GATED (Step 12 / ADR-0024)

The Phase 7 witness-diff harness was measurement-only by design (Plan 03 D-06 contract); a regression that doubled the divergence numbers would have passed CI silently. Step 12 (commit 009b636) lands `config/witness_diff_thresholds.json` with per-preset low-band ceilings + `tests/python/test_witness_thresholds.py` (ctest target `witness_thresholds`, label `witness`) that asserts each pair stays at-or-below its preset's threshold. ADR-0024 documents the policy + the explicit `off`-preset skip rule. Initial thresholds are deliberately liberal (regression gate, not correctness gate); M2 will tighten after lv2 baseline calibration.

### 5. No External Anchor for spu94_process Correctness → CLOSED

The witness-diff harness, golden files, modulation harness, and self-test all confirmed REPRODUCIBILITY but none confirmed CORRECTNESS against an externally-derived value. Step 13 (commit 06e5b40) adds `tests/unit/process/test_process_external_anchor_off.c` — Off preset's all-zero gain registers algebraically force the SPU reverb's output to identically zero for any input, and the test asserts exactly that across 80 samples per channel (covers > 2× the 39-tap FIR group delay). Catches dry-path leak, broken vLIN/vLOUT gating, accidental routing, and state corruption in a single test.
