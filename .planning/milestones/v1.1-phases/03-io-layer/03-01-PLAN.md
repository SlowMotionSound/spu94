**Create `include/spu94/spu94_vag.h`** — public VAG API header (per D-07: library module, peer alongside codec):

```c
#ifndef SPU94_VAG_H
#define SPU94_VAG_H

#include <stdint.h>
#include <stddef.h>

#ifdef __cplusplus
extern "C" {
#endif

#define SPU94_VAG_HEADER_BYTES 48

typedef struct {
    uint32_t version;
    uint32_t data_size;     /* bytes of ADPCM data after header (num_blocks * 16) */
    uint32_t sample_rate;
    char     name[16];      /* null-terminated ASCII, zero-padded */
} spu94_vag_header;

/* VAG block flag values relevant to SPU-94 */
#define SPU94_VAG_FLAG_NORMAL     0x00
#define SPU94_VAG_FLAG_END        0x01
#define SPU94_VAG_FLAG_TERMINATOR 0x07

/* Read and validate a 48-byte VAG header from buf.
 * Returns 0 on success, -1 if magic != "VAGp".
 * Accepts any version value on read (per ADPCM-IO-03).
 * Per D-08: operates on caller-provided buffer, zero heap. */
int spu94_vag_read_header(const uint8_t buf[SPU94_VAG_HEADER_BYTES],
                          spu94_vag_header *out);

/* Write a 48-byte VAG v2 header into buf.
 * Per D-08: caller provides the buffer. Zero heap.
 * version is always 2 on write (per ADPCM-IO-04). */
void spu94_vag_write_header(uint8_t buf[SPU94_VAG_HEADER_BYTES],
                            uint32_t data_size,
                            uint32_t sample_rate,
                            const char *name);

#ifdef __cplusplus
}
#endif

#endif /* SPU94_VAG_H */
```

**Create `src/spu94/vag.c`** — VAG reader/writer implementation:
- `read_be32()` static inline: `((uint32_t)p[0] << 24) | ((uint32_t)p[1] << 16) | ((uint32_t)p[2] << 8) | (uint32_t)p[3]` — no `ntohl` per ADPCM-IO-03.
- `write_be32()` static inline: `p[0] = (uint8_t)(v >> 24)` etc.
- `spu94_vag_read_header`: validate magic bytes 'V','A','G','p'. Parse version at offset 0x04, data_size at 0x0C, sample_rate at 0x10 via `read_be32()`. Copy 16 bytes from offset 0x20 into name, force null-terminate at index 15. Return -1 on bad magic, 0 on success.
- `spu94_vag_write_header`: `memset(buf, 0, 48)`. Write "VAGp" magic at offset 0. Write version=2 at offset 0x04 via `write_be32`. Write data_size at 0x0C, sample_rate at 0x10. Copy name (up to 15 chars) into offset 0x20 if non-NULL.

Includes: `spu94_adpcm.h`, `spu94_vag.h`, `wav_io.h`, `<getopt.h>`, `<stdio.h>`, `<stdlib.h>`, `<string.h>`, `<stdint.h>`.

`int cmd_adpcm_encode(int argc, char **argv)`:
- Parse: `--help` / `-h`. Positional: INPUT.wav OUTPUT.vag.
- Load WAV via `spu94_cli_wav_load`.
- Stereo handling per D-04: process L and R as separate mono ADPCM streams. VAG output = L header + L blocks + R header + R blocks (dual-sequential).
- For each channel: compute `num_blocks = (num_frames + SPU94_ADPCM_BLOCK_SAMPLES - 1) / SPU94_ADPCM_BLOCK_SAMPLES`. Data size = `num_blocks * SPU94_ADPCM_BLOCK_BYTES`.
- Write VAG header via `spu94_vag_write_header(hdr_buf, data_size, sample_rate, "spu94")`.
- Encode each block via `spu94_adpcm_encode_block`. Zero-pad the final block to 28 samples. Set flags=0x00 for all blocks except the last, which gets flags=0x01 (per ADPCM-IO-04).
- Write header + blocks to output file via fwrite.
- Repeat for R channel if stereo.
- Free WAV buffers, return 0.

`int cmd_adpcm_decode(int argc, char **argv)`:
- Parse: `--help` / `-h`. Positional: INPUT.vag OUTPUT.wav.
- Read first 48 bytes from input file. Parse via `spu94_vag_read_header`.
- Compute `num_blocks = data_size / SPU94_ADPCM_BLOCK_BYTES`.
- Allocate output buffer: `num_blocks * SPU94_ADPCM_BLOCK_SAMPLES` samples.
- Read and decode blocks one at a time via `spu94_adpcm_decode_block`. Stop on flag 0x01 or 0x07 (per ADPCM-IO-03).
- Check for second VAG header (dual-mono stereo per D-04): after first stream's data, attempt to read another 48 bytes. If magic is "VAGp", decode second stream as R channel. Otherwise, treat as mono (duplicate L to R for WAV output).
- Write WAV via `spu94_cli_wav_write`.

`int cmd_adpcm_roundtrip(int argc, char **argv)`:
- Parse: `--help` / `-h`. Positional: INPUT.wav OUTPUT.wav.
- Per D-02: encode to ADPCM in memory then decode back. No intermediate .vag file.
- Load WAV via `spu94_cli_wav_load`. Allocate output buffers same size.
- For each channel (L, R): loop over 28-sample blocks. Zero-pad last block. Encode via `spu94_adpcm_encode_block` with flags=0x00. Decode via `spu94_adpcm_decode_block`. Copy decoded samples to output.
- Write output WAV via `spu94_cli_wav_write`.
