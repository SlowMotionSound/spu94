# v1.7 Requirements: DAW Plugin Port

**Milestone:** v1.7
**Status:** Draft — pre-roadmap
**Drafted:** 2026-05-11
**Inputs:** `.planning/research/{STACK,FEATURES,ARCHITECTURE,PITFALLS,SUMMARY}-v1.7.md` + `HANDOFF.json`

## Milestone Goal

Package the bit-faithful SPU-94 engine as a real-time DAW plugin in four formats (VST3, AU, LV2, CLAP) across three operating systems (Linux, macOS, Windows). Preserve the C core untouched; sample-rate conversion and bit-depth conversion live entirely in the plugin wrapper. Standalone build target is retained as an internal dev testbed but is no longer a user deliverable.

## Locked Decisions (inputs, not requirements)

| Topic | Decision |
|---|---|
| Plugin formats | VST3 + AU + LV2 + CLAP (LV2 dropped on Windows) |
| OS targets | Linux + macOS + Windows |
| Total binaries | 11 (4 Linux + 4 macOS + 3 Windows) |
| C core | untouched; SR + bit-depth compatibility is wrapper-only |
| SRC library | libsamplerate (BSD-2), Sinc Medium quality preset |
| Dither at float→int16 | Truncate (no dither) — period-faithful per North Star |
| Folder layout | `src/standalone/` → `src/plugin/`; new small `src/standalone/` holds testbed-only files (WavLoader) |
| Standalone status | Internal dev testbed, not shipped to users |
| Channel buses | mono→mono, mono→stereo, stereo→stereo; mono duplicated into both reverb inputs |
| GUI | Current standalone GUI reused inside plugin window; no v1.7 redesign |
| Code signing | Skipped for beta; testers click through Gatekeeper / SmartScreen |
| CLAP path | clap-juce-extensions shim (JUCE 8 lacks native CLAP) |

## Requirements

### Build & Format Matrix

- [ ] **PLUG-01**: VST3 built for Linux, macOS, Windows
- [ ] **PLUG-02**: AU built for macOS only
- [ ] **PLUG-03**: LV2 built for Linux only (Windows LV2 explicitly excluded from build matrix)
- [ ] **PLUG-04**: CLAP built for Linux, macOS, Windows
- [ ] **PLUG-05**: Standalone build target retained; not bundled in user-facing distribution
- [ ] **PLUG-06**: clap-juce-extensions integrated via CMake `FetchContent`
- [ ] **PLUG-07**: GitHub Actions matrix builds all 11 user-facing binaries on every push to `main`
- [ ] **PLUG-08**: Each binary passes a builds-and-loads smoke test in at least one host of its native format

### Sample-Rate Conversion (host ↔ 44.1 kHz core)

- [ ] **PLUG-09**: libsamplerate (BSD-2) integrated as the SRC library
- [ ] **PLUG-10**: SRC operates in `SRC_SINC_MEDIUM_QUALITY` preset at default
- [ ] **PLUG-11**: SRC operates bidirectionally — host SR → 44.1 kHz at input, 44.1 kHz → host SR at output
- [ ] **PLUG-12**: All SRC buffers and state are allocated in `prepareToPlay`; zero allocation on the audio thread (RT-safety hard rule)
- [ ] **PLUG-13**: When `hostSampleRate == 44100.0`, SRC is bypassed entirely (fast path; no resampling roundtrip)
- [ ] **PLUG-14**: `setLatencySamples()` reports the measured `SRC_in + core + SRC_out` group delay — measured at integration time, not estimated from documentation
- [ ] **PLUG-15**: Null-test confirms PDC (Plugin Delay Compensation) alignment in Reaper at 48 kHz host SR
- [ ] **PLUG-16**: `ScopedNoDenormals` guard wraps `processBlock` to prevent denormal CPU spikes

### Float ↔ int16 Boundary

- [ ] **PLUG-17**: Host float32 input converted to int16 via clamp + truncation (no dither, no noise shaping) — preserves North Star period-faithful behavior
- [ ] **PLUG-18**: Input clamp/saturation matches the C core's `sat_s16` semantics (ADR-0001) — no integer wrap on overflow
- [ ] **PLUG-19**: Default Input Gain initialized to 0.5 (-6 dB) matching the standalone default
- [ ] **PLUG-20**: Existing side-channel limiter (`PluginProcessor.cpp:357-377`) preserved unchanged
- [ ] **PLUG-21**: int16 core output converted back to host float32 by division by 32768.0f

### State Persistence

- [ ] **PLUG-22**: `getStateInformation` writes the existing `.spu94` byte payload wrapped in a binary container
- [ ] **PLUG-23**: `setStateInformation` reads the wrapped payload and applies it via the existing `pendingPresetBuf` deferred-apply mechanism (no allocation on the audio thread)
- [ ] **PLUG-24**: State container format: 4-byte magic `'SPU9'` + 1-byte version + 4-byte body length + body bytes
- [ ] **PLUG-25**: State round-trip path is locale-independent — no `juce::String::getFloatValue` in the persistence chain (avoids the German/French `1,5` parsing bug)
- [ ] **PLUG-26**: Save → close session → reopen → load produces a byte-identical engine state in every supported host
- [ ] **PLUG-27**: Multi-instance smoke test: two plugin instances on independent tracks retain independent state across save/load

### Host Automation Parameter Surface

- [ ] **PLUG-28**: Exactly 9 `juce::AudioProcessorParameter`s are exposed for host automation:
  - Input Gain, ADPCM Send, Dry Send
  - Morph Position, Morph Speed, Morph Grit
  - Dry Level, ADPCM Level, Reverb Level
- [ ] **PLUG-29**: All 9 parameters routed through the existing atomic-scalar + SPSC `RegisterBridge` pattern (not APVTS — see ARCHITECTURE-v1.7.md §5.1)
- [ ] **PLUG-30**: Parameter IDs stable across versions — once a parameter ID is published, it is never reassigned or repurposed
- [ ] **PLUG-31**: Audio-block-granularity automation is sufficient; per-sample-accurate CLAP automation is explicitly out of scope (acceptable for reverb)

### Channel Bus Configuration

- [ ] **PLUG-32**: `isBusesLayoutSupported` declares exactly three configurations: mono→mono, mono→stereo, stereo→stereo
- [ ] **PLUG-33**: Mono input is duplicated into both L and R reverb inputs (engine always operates stereo internally)
- [ ] **PLUG-34**: mono→mono output sums internal L+R back to mono at the output stage
- [ ] **PLUG-35**: All other configurations — sidechain, surround, Atmos, multi-bus — are rejected
- [ ] **PLUG-36**: Plugin loads on a mono track in Logic without `auval` failure

### Validation & Quality Gates (CI)

- [ ] **PLUG-37**: `pluginval --strictness-level 7` runs on every build of every format on every OS
- [ ] **PLUG-38**: `auval -v aufx <chosen-codes>` runs on every macOS build
- [ ] **PLUG-39**: `lv2lint` + `sord_validate` run on every Linux LV2 build
- [ ] **PLUG-40**: VST3 SDK `validator` runs on every VST3 build
- [ ] **PLUG-41**: pluginval RT-safety probe reports zero allocations on the audio thread
- [ ] **PLUG-42**: Any validator warning or error fails the CI build (warnings are not advisory)

### Packaging & Distribution

- [ ] **PLUG-43**: macOS distribution: `.pkg` installer OR drag-install `.dmg`, placing each format in its standard scan path
- [ ] **PLUG-44**: Windows distribution: Inno Setup installer placing binaries in standard host scan paths
- [ ] **PLUG-45**: Linux distribution: tarball + `install.sh` placing binaries under `~/.vst3`, `~/.lv2`, `~/.clap`
- [ ] **PLUG-46**: Beta README documents per-host plugin-cache reset procedure (handles stale-cache symptoms in tester feedback loop)
- [ ] **PLUG-47**: Beta README documents per-OS workaround for unsigned binaries (macOS Gatekeeper, Windows SmartScreen)
- [ ] **PLUG-48**: Plugin window is fixed-size — matches current standalone GUI; resizable contract not declared

### Standalone Testbed (non-shipping)

- [ ] **PLUG-49**: WAV-loader UI is gated on `wrapperType == wrapperType_Standalone` — invisible in every plugin format
- [ ] **PLUG-50**: Source tree reorganized: `src/standalone/` → `src/plugin/`; `WavLoader.{cpp,h}` moves into new small `src/standalone/` folder
- [ ] **PLUG-51**: Standalone build remains green throughout v1.7; v1.6 GUI behavior unchanged in standalone mode

### Code Signing (deferred)

- [ ] **PLUG-52**: Code signing is intentionally deferred for the v1.7 beta — no Developer ID or OV cert required for ship
- [ ] **PLUG-53**: Re-evaluated reactively if beta testers report install friction; no firm phase scope unless triggered
