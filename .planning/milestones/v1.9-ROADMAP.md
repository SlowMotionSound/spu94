## Overview

Makes each SPU-94S voice feature-complete to the PS1 SPU spec. ADSR envelope correction, signed volume with phase inversion, voice-to-voice pitch modulation (PMON), global LFSR noise generator (NON), hardware-driven volume sweep with independent L/R state machines, and musician-facing GUI controls (pan/level, feature toggles, VCA ramp). Every voice is now a fully capable PS1 voice before multi-timbral or dynamics effects are layered on.

### Phase 36: Noise Generator (NON)

**Goal**: Voices can output LFSR pseudo-random noise instead of ADPCM
**Depends on**: Phase 35
**Plans**: 2 plans

- [x] 36-01-PLAN.md -- TDD: noise generator LFSR module + NON voice pipeline integration (NON-01..08)
- [x] 36-02-PLAN.md -- ADR-0058 noise generator decisions documentation (NON-09)

**Details:** Single global LFSR (taps 15,12,11,10 XOR 1, seed=1, left-shift). Timer-based frequency from SPUCNT NoiseShift/NoiseStep. Ticks once globally before voice loop. ADPCM still decodes for flag side effects. ADR-0058 documents polynomial source and design decisions.

### Phase 37: Volume Sweep

**Goal**: Per-voice volume ramps automatically via hardware-driven sweep, independent of ADSR
**Depends on**: Phase 36
**Plans**: 3 plans

- [x] 37-01-PLAN.md -- TDD: extract shared envelope step helper from ADSR, refactor ADSR to use it (SWEEP-03, SWEEP-04)

## Milestone Summary

**Key Decisions:**

- ADR-0056: Decrease formulas use base 8 per nocash spec; increase formulas use base 7
- ADR-0057: VxOUTX capture point is post-ADSR, pre-volume (DuckStation-confirmed)
- ADR-0058: Noise LFSR polynomial taps 15,12,11,10 XNOR, seed=1, ADPCM always decodes for NON voices
- ADR-0059: Negative-phase sweep is LOW confidence (nocash "not yet tested")
- Call volume sweep "VCA ramp" in user-facing contexts (sweep is Sony register jargon)
- Label exponential curve as "Exponential" not "Natural" (accurate terminology)
- Raw unfiltered noise only — Gauss filter experiment reverted
- Pan/Level are static controls; VCA ramp is modulation layer — don't tie fader to ramp
- Voice Dynamics & Stereo Effects deferred to its own milestone

**Issues Resolved:**

- ADSR sustain-decrease off-by-one (pre-existing from v1.8, corrected per spec)
- Double-speed playback bug (pitch knob default 0x1000 corrected to 0x800)
- Continuous Pan/Level (previously interrupted on each update)
- NON without sample loaded (crash fix)
- Noise audibility at low shift values

**Issues Deferred:**

- MIDI dispatch regression test (deferred to plugin port milestone — Linux standalone MIDI unreliable)
- Voice Dynamics & Stereo Effects (next milestone: tremolo, auto-pan, sidechain duck, stereo widener, AM synthesis, phase modulator)
- Internal mod bus (route global noise as control signal to pitch/volume/pan per voice)

**Technical Debt Incurred:**
