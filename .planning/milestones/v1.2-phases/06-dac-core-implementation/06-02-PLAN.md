<objective>
Implement the AK4309 delta-sigma noise model as a standalone C module with LFSR white noise source and 2nd-order highpass shaping, producing +12dB/octave spectral slope calibrated to approximately -90dB dynamic range.

Purpose: The AK4309 is a 1-bit delta-sigma DAC whose quantization noise has a characteristic rising spectral shape from the 2nd-order noise transfer function (1-z^-1)^2. This module models that noise floor as a subtle coloration -- inaudible on most material, but contributing to the authentic PS1 "texture" on quiet passages and reverb tails.

Output: spu94_dac_noise module (public header + implementation) with unit tests proving LFSR behavior, spectral slope, and amplitude calibration.
</objective>

**include/spu94/spu94_dac_noise.h** (per D-07/D-09 standalone module pattern):
```c
#ifndef SPU94_DAC_NOISE_H
#define SPU94_DAC_NOISE_H
#include <stdint.h>
#ifdef __cplusplus
extern "C" {
#endif

typedef struct {
    uint32_t lfsr;      /* 32-bit Galois LFSR state */
    int16_t  x_prev;    /* x[n-1] for 2nd-order HP shaping */
    int16_t  x_prev2;   /* x[n-2] for 2nd-order HP shaping */
} spu94_dac_noise_state;

/* Generate one shaped noise sample at 44.1kHz.
 * Returns a Q15 noise sample with +12dB/octave spectral slope,
 * calibrated to approximately -90dB RMS in the audio band.
 *
 * WARNING: spu94_dac_noise_init() MUST be called before first use.
 * memset(state, 0, sizeof(*state)) is NOT equivalent -- it sets the
 * LFSR to zero, which is an absorbing state (output = silence forever).
 * This is the one exception to the project convention where zero-init
 * is correct. */
int16_t spu94_dac_noise_step(spu94_dac_noise_state *state);

/* Initialize noise state with a non-zero LFSR seed.
 * MUST be called instead of memset for this module (see warning above). */
void spu94_dac_noise_init(spu94_dac_noise_state *state);

#ifdef __cplusplus
}
#endif
#endif /* SPU94_DAC_NOISE_H */
```

**src/spu94/spu94_dac_noise.c**:

Header comment block documenting:
- Module purpose (AK4309 delta-sigma noise model)
- LFSR polynomial: x^32 + x^22 + x^2 + x^1 + 1, feedback mask 0x80200003, period 2^32-1
- 2nd-order HP shaping: y[n] = x[n] - 2*x[n-1] + x[n-2], equivalent to NTF(z) = (1-z^-1)^2
- Amplitude target: ~-90 dB SNR per AK4309B datasheet (D-04). Paper target, placeholder for M5 hardware calibration (D-05).
- Reference: .planning/research/DEEP-DELTA-SIGMA.md

```c
#include <spu94/spu94_dac_noise.h>
#include <spu94/spu94_q15.h>
#include <string.h>

/* LFSR polynomial: x^32 + x^22 + x^2 + x^1 + 1 (Galois form).
 * Maximal-length: period = 2^32 - 1 = 4,294,967,295.
 * At 44.1 kHz, repeats every ~27 hours -- effectively infinite. */
#define DAC_NOISE_LFSR_FEEDBACK  0x80200003u
#define DAC_NOISE_LFSR_SEED      0xACE1u  /* arbitrary non-zero seed */

/* Amplitude scaling: right-shift raw LFSR output to target ~-90 dB RMS
 * in the audio band after 2nd-order HP shaping. This is a compile-time
 * constant, tunable per D-06 ("treat the level as tunable later").
 * Derivation: RESEARCH.md Noise Amplitude Derivation section.
 * Validated by tests/unit/dac_noise/test_dac_noise_amplitude.c. */
#define DAC_NOISE_SHIFT  9

void spu94_dac_noise_init(spu94_dac_noise_state *state) {
    memset(state, 0, sizeof(*state));
    state->lfsr = DAC_NOISE_LFSR_SEED;
}

int16_t spu94_dac_noise_step(spu94_dac_noise_state *state) {
    /* Step the Galois LFSR */
    uint32_t lfsr = state->lfsr;
    uint32_t bit = lfsr & 1u;
    lfsr >>= 1;
    if (bit) lfsr ^= DAC_NOISE_LFSR_FEEDBACK;
    state->lfsr = lfsr;

    /* Scale LFSR output to noise amplitude.
     * Take upper 16 bits, center around zero, then right-shift. */
    int16_t x = (int16_t)(((int32_t)(lfsr >> 16) - 32768) >> DAC_NOISE_SHIFT);

    /* 2nd-order highpass shaping: y[n] = x[n] - 2*x[n-1] + x[n-2]
     * This is the discrete NTF (1 - z^-1)^2 from delta-sigma theory.
     * Produces +12 dB/octave spectral slope. */
    int32_t y = (int32_t)x - 2 * (int32_t)state->x_prev + (int32_t)state->x_prev2;
    state->x_prev2 = state->x_prev;
    state->x_prev = x;

    return sat_s16(y);
}
```

Note: The `(lfsr >> 16)` extracts the upper 16 bits of the 32-bit LFSR which have better statistical properties than the lower bits for a Galois LFSR.

**tests/unit/dac_noise/test_dac_noise_spectral.c**:
This test verifies the +12 dB/octave spectral slope characteristic.

Approach (pure C, no FFT library needed):
- Generate N=8192 noise samples via spu94_dac_noise_step.
- Compute power at two frequencies using the Goertzel algorithm (a single-frequency DFT bin).
  Pick f1 = 2000 Hz and f2 = 8000 Hz (two octaves apart).
  At 44100 Hz sample rate: bin for 2000 Hz = round(2000/44100 * 8192) = 372, bin for 8000 Hz = round(8000/44100 * 8192) = 1486.
- Goertzel gives magnitude squared at each bin. Convert to dB: power_dB = 10*log10(mag_sq).
- The slope between f1 and f2 should be approximately +12 dB/octave. Two octaves span means expected difference = 24 dB.
- Assert: (power_f2_dB - power_f1_dB) is between 18 dB and 30 dB (generous tolerance because noise has variance; the shaped spectrum is statistical, not deterministic).

Alternative: Average over multiple runs or use a larger N for tighter tolerance.

Implement Goertzel inline (it's ~10 lines of floating-point math, acceptable in a test file -- the float-free gate applies to libspu94, not test executables).

```c
/* Goertzel algorithm: compute |DFT[k]|^2 for a single bin k over N samples. */
static double goertzel_mag_sq(const int16_t *samples, int N, int k) {
    double w = 2.0 * 3.14159265358979323846 * (double)k / (double)N;
    double coeff = 2.0 * cos(w);
    double s0 = 0, s1 = 0, s2 = 0;
    for (int i = 0; i < N; i++) {
        s0 = (double)samples[i] + coeff * s1 - s2;
        s2 = s1;
        s1 = s0;
    }
    return s1*s1 + s2*s2 - coeff*s1*s2;
}
```

Include `<math.h>` in the test file. Link with `-lm` in CMakeLists.txt for this test only.

**tests/unit/dac_noise/test_dac_noise_amplitude.c**:
Verify noise RMS is near -90 dB target.

- Generate N=44100 noise samples (1 second at 44.1kHz).
- Compute RMS: sqrt(sum(x^2)/N) using int64_t accumulator for sum of squares.
- Convert to dB: 20*log10(rms / 32768.0).
- Assert: RMS level is between -100 dB and -80 dB (generous +-10 dB window per D-04/D-06 -- the shaping character matters more than the absolute amplitude, and the exact level is tunable).

If the NOISE_SHIFT constant produces a level outside this window, the test documents the actual level and the constant can be tuned. The important invariant is that the noise is in the right ballpark -- not silence, not audible hiss.
