<objective>
Add threshold-triggered recording to the sampler. Extends the 3-state recording state machine (IDLE / RECORDING / STOPPED) with a 4th state (ARMED). When armed, the audio thread monitors input level and auto-starts recording when signal exceeds a user-set threshold. The record button cycles through all states with distinct color feedback.

Purpose: Enables hands-free recording -- the user arms, plays their instrument, and capture begins on the first note without losing the attack transient.
Output: Working threshold trigger with adjustable threshold knob and tri-state record button display.
</objective>

       if (recState == REC_RECORDING) { ... capture samples ... }
       else { ... just compute peak ... }

       Change to:
       if (recState == REC_RECORDING) { ... existing capture code, unchanged ... }
       else if (recState == REC_ARMED) {
           // Compute peak the same way as the else branch (mono-sum, track max abs)
           // ALSO check each sample against the threshold:
           float thresh = recordingThreshold.load(std::memory_order_relaxed);
           bool triggered = false;
           int triggerSample = 0;
           for (int i = 0; i < n; ++i) {
               float mono = (inL[i] + inR[i]) * 0.5f;
               float absMono = (mono < 0.0f) ? -mono : mono;
               if (absMono > peak) peak = absMono;
               if (!triggered && absMono > thresh) {
                   triggered = true;
                   triggerSample = i;
               }
           }
           inputPeakLevel.store(peak, std::memory_order_relaxed);

           if (triggered) {
               // Transition to recording and capture FROM the trigger sample onward
               // (don't lose the transient that crossed the threshold)
               recordingState.store(REC_RECORDING, std::memory_order_release);
               for (int i = triggerSample; i < n; ++i) {
                   float mono = (inL[i] + inR[i]) * 0.5f;
                   float scaled = mono * 32768.0f;
                   if (scaled > 32767.0f) scaled = 32767.0f;
                   if (scaled < -32768.0f) scaled = -32768.0f;
                   if (recordStagingCount < recordStagingCapacity)
                       recordStagingBuffer[recordStagingCount] = static_cast<int16_t>(scaled);
                   ++recordStagingCount;
               }
               uint32_t estBytes = static_cast<uint32_t>(
                   ((recordStagingCount + 27u) / 28u) * 16u);
               recordBytesUsed.store(estBytes, std::memory_order_relaxed);
           }
       }
       else { ... existing peak-only code ... }

       The key detail: when the threshold is crossed partway through a block, capture starts from that exact sample (triggerSample index), so the attack transient is preserved.
