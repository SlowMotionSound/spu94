### Blockers/Concerns

#### Open Bugs (found during Phase 23 visual checkpoint)
1. **Sync mode echo snap-to-0**: Toggling Sync on in Echo Physics section causes all echo speed registers to snap to 0 and produces feedback. Root cause: the snap module's 0xFF "unset" sentinel means registers on "Global" don't participate in Sync mode transforms. The C core snap module needs to be aware of the global subdivision to resolve 0xFF slots. Attempted GUI-layer resolution caused worse side effects (register overwrites when BPM unset).
2. **Rotate only works with all 4 dropdowns explicitly set**: Because 0xFF slots are skipped in the snap apply chain, Rotate with partial dropdown selections produces unexpected results. Needs C core change to either resolve 0xFF to a fallback or only permute among set slots.
3. **Room Size at high values causes feedback**: Large room sizes push delay lines long enough that the reverb self-oscillates with the Hall preset's feedback coefficients. Expected SPU behavior but needs tolerance tuning (knob range limits or dynamic coefficient reduction).
