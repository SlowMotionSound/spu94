D-09 latency contract (04-RESEARCH § Decision Proposals):
- Decimator group delay: 19 samples at 44.1 kHz
- Interpolator group delay: 19 samples at 44.1 kHz
- Total chain latency: 38 samples at 44.1 kHz
- Public accessor: `uint32_t spu94_get_latency_samples(void)` returns 38u
- Macro form: `#define SPU94_LATENCY_SAMPLES 38u` in include/spu94/spu94.h
- Accessor body: `return SPU94_LATENCY_SAMPLES;` (single-line — LTO-eliminable)

Chain wrapper state-machine (04-RESEARCH § Pattern 3):
- Every 44.1 kHz call pushes one stereo sample into the decimator.
- Decimator produces a 22.05 kHz output on every-OTHER call (retained phase).
- When the retained phase fires: call spu94_tick(state) to process the 22.05 kHz reverb network; then call spu94_fir_interpolate() which produces BOTH phase-0 and phase-1 44.1 kHz outputs. Cache phase-1 in state->pending fields (added by Plan 03); emit phase-0 now.
- On the non-retained call: emit the cached phase-1 from the previous tick.
- This matches 04-RESEARCH's Pattern 3 wrapper sketch.
- New state fields Plan 03 adds: `int16_t fir_pending_l_phase1; int16_t fir_pending_r_phase1;` (2 × int16 = 4 bytes). Zeroed by spu94_reset wholesale.

Reverb-bypass variant:
- Identical to spu94_fir_chain_step EXCEPT on the retained-phase branch, instead of calling spu94_tick, the 22.05 kHz L+R values are passed unchanged into spu94_fir_interpolate.
- Used by test_fir_impulse, test_fir_dc to characterize the FIR chain without reverb contamination.

Pitfall 7 (04-RESEARCH Pitfall 7, "Interpolator phase-0 / phase-1 emission ordering"): the wrapper's phase-tracking state is a single `state->fir_interpolate_phase` int (0/1). The interpolator stage (spu94_fir_interpolate) is stateless on the phase axis — it produces both phases every call. The wrapper chooses which to emit.

    static void chain_step_impl(spu94_state *state,
                                int16_t l_in, int16_t r_in,
                                int16_t *l_out, int16_t *r_out,
                                int reverb_active) {
        int16_t dec_l = 0, dec_r = 0;
        int dec_valid = 0;
        spu94_fir_decimate(state, l_in, r_in, &dec_l, &dec_r, &dec_valid);

        if (dec_valid) {
            /* Retained phase — produce new 22.05 kHz sample, then interpolate
             * into a 44.1 kHz pair (phase-0 emitted now, phase-1 cached). */
            if (reverb_active) {
                spu94_tick(state);

            int16_t p0_l = 0, p0_r = 0, p1_l = 0, p1_r = 0;
            spu94_fir_interpolate(state, dec_l, dec_r,
                                  &p0_l, &p0_r, &p1_l, &p1_r);

            if (r_out) *r_out = p0_r;

            state->fir_pending_r_phase1 = p1_r;

            if (r_out) *r_out = state->fir_pending_r_phase1;
            state->fir_interpolate_phase = 0u;
        }
    }
