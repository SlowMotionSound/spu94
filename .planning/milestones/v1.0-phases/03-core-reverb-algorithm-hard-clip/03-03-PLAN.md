Nocash E1 (verbatim):

```
;Early Echo (Comb Filter, with input from buffer)
Lout = vCOMB1*[mLCOMB1] + vCOMB2*[mLCOMB2] + vCOMB3*[mLCOMB3] + vCOMB4*[mLCOMB4]
Rout = vCOMB1*[mRCOMB1] + vCOMB2*[mRCOMB2] + vCOMB3*[mRCOMB3] + vCOMB4*[mRCOMB4]

;Late Reverb APF1 (All Pass Filter 1, with input from COMB)
Lout = Lout - vAPF1*[mLAPF1-dAPF1], [mLAPF1] = Lout, Lout = Lout*vAPF1 + [mLAPF1-dAPF1]
Rout = Rout - vAPF1*[mRAPF1-dAPF1], [mRAPF1] = Rout, Rout = Rout*vAPF1 + [mRAPF1-dAPF1]

;Late Reverb APF2 (All Pass Filter 2, with input from APF1)
Lout = Lout - vAPF2*[mLAPF2-dAPF2], [mLAPF2] = Lout, Lout = Lout*vAPF2 + [mLAPF2-dAPF2]
Rout = Rout - vAPF2*[mRAPF2-dAPF2], [mRAPF2] = Rout, Rout = Rout*vAPF2 + [mRAPF2-dAPF2]
```

**D-07 LOCKED: comb sum uses cascading `sat_s16` after each add, NOT int32 accumulate.** Per CONTEXT.md:
> "the 4-tap comb sum clamps after every intermediate add rather than accumulating in int32 and clamping once at the end. Rationale (user, taste-driven): more distortion character at input extremes, richer overflow signal feeding the D-11 err accumulator"

This diverges from the DuckStation/Mednafen-PSX behavioral witness (int32 accumulate). Revert lever documented in ADR-0007.

Register enum values used here:
- vCOMB1..4 (i16), mLCOMB1..4 + mRCOMB1..4 (u16), vAPF1, vAPF2 (i16), dAPF1, dAPF2 (u16), mLAPF1, mRAPF1, mLAPF2, mRAPF2 (u16).
