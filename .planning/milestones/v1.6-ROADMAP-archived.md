## Phase Details

### Phase 20: Macro Engine + Safety Core
**Goal**: The C core has a macro engine that scales register groups proportionally from their current state, gang-clamps when any member hits a ceiling/floor, recalculates knob range dynamically, re-derives macro positions from raw state, and enforces the vIIR x vWALL stability ceiling and address bounds checking at the engine level
**Depends on**: Phase 19 (v1.5 complete)
**Requirements**: MACRO-01, MACRO-02, MACRO-03, MACRO-04, MACRO-05, SAFE-01, SAFE-02
**Success Criteria** (what must be TRUE):
  1. A macro knob set to 50% on a group of registers produces values that are proportionally between the group's current floor and ceiling -- not absolute values from a lookup table
  2. When a single register in a gang-clamped group hits its ceiling, sweeping the knob further does not change any register in the group -- all stop together and ratios hold
  3. After manually editing a raw register that belongs to a macro group, switching to macro mode shows a knob position that reflects the current register state (not the last macro position)
  4. Setting vIIR and vWALL to values whose product exceeds the stability ceiling results in clamping -- the engine refuses to let the product go unstable
  5. Setting an m-prefix address register to a value that would exceed the work buffer (mBASE) results in clamping to the buffer boundary
**Plans:** 2 plans
Plans:
- [x] 20-01-PLAN.md -- Safety enforcement layer (vIIR x vWALL ceiling + m-prefix address bounds)
- [x] 20-02-PLAN.md -- Macro engine (proportional scaling, gang clamping, dynamic range, re-derivation)

### Phase 21: Macro Controls
**Goal**: Full Room Designer control surface defined in the C core -- walls with paired echo speeds and link toggles, tap positions with constrained/unconstrained mode, diffusion section (amount/texture/position), Room Size master, Buffer (mBASE) control, Decay/Reflectivity coupling, Early Reflections -- all wired through the Phase 20 macro engine with Spread+Sweep model, bipolar knob support, vIIR safety constraints, and preset-to-macro derivation proven
**Depends on**: Phase 20
**Requirements**: WALL-01..06, ECHO-SPD-01, TAP-01..03, DIFF-AMT-01, DIFF-TEX-01, DIFF-POS-01..02, ROOM-01, BUF-01..02, SS-01..03, CTRL-01..03, SAFE-03, SAFE-04, PRESET-01
**Success Criteria** (what must be TRUE):
  1. Room Size master proportionally scales all 14 m-prefix address registers while gang clamping at mBASE boundary; also scales echo speeds when per-wall link toggles are active
  2. Each wall (Left Wall, Right Wall, Left Cross, Right Cross) has paired distance + echo speed controls; link toggle tethers echo speed to distance proportionally; same/cross link toggle available for physical realism
  3. Tap Positions: 8 individual controls independently positioned; Spread+Sweep macro on top; wall constrained/unconstrained toggle clamps taps within wall boundaries when active
  4. Diffusion section: Amount (vAPF1/2), Texture (dAPF1/2), Position (mLAPF1/mRAPF1/mLAPF2/mRAPF2) each with Spread+Sweep; position has individual controls + constrained/unconstrained toggle
  5. Buffer control (mBASE): fully up = max space, pull down = crush; safety layer clamps m-prefix registers at shrinking boundary
  6. Decay bipolar center-detent (vIIR): left = negative (-0x1000 to 0), right = positive (0 to 0x7FFF), cannot reach -0x8000
  7. Reflectivity bipolar center-detent (vWALL): auto-rederives when Decay changes; stability-coupled ceiling
  8. Early Reflections Spread+Sweep (vCOMB1-4): spread collapses to zero / exaggerates proportionally; sweep slides through signed range
  9. All Spread+Sweep macros use preset register values as reference anchor; user can override in advanced mode
  10. Loading a .spu94 preset sets register values and all macros derive their positions from register state without altering any register value
**Plans:** 3 plans
Plans:
- [x] 21-01-PLAN.md -- Engine extensions (Spread+Sweep apply, bipolar apply, reference values, enum expansion)
- [x] 21-02-PLAN.md -- Group definitions + link/constrain (10 group tables, registration, wall links, constrained mode)
- [x] 21-03-PLAN.md -- Coupling + Buffer + preset integration (Decay/Reflectivity coupling, Buffer apply, derive-all)

### Phase 22: Echo Speed + Diffusion Snap
**Goal**: Echo Speed and Diffusion Texture controls integrate with the v1.5 tempo system via a Sync/Free modal toggle -- Free mode uses continuous Phase 21 Spread+Sweep, Sync mode quantizes all 4 echo speed registers to subdivision table positions with discrete Sweep (shift pattern faster/slower), Spread (unison to polyrhythmic), and Rotate (Euclidean permutation) transforms operating on per-register dropdown selections as the reference anchor
**Depends on**: Phase 21, Phase 16-19 (v1.5 tempo system)
**Requirements**: SNAP-01, SNAP-02, SNAP-03
**Success Criteria** (what must be TRUE):
  1. Binary Sync/Free toggle switches the entire echo speed section between continuous (Phase 21 Spread+Sweep) and discrete subdivision-quantized operation -- all 4 registers toggle together
  2. In Sync mode, each register has a per-register subdivision dropdown selection that becomes the reference state for Sweep/Spread/Rotate transforms
  3. Sweep shifts all 4 registers up/down the duration-sorted subdivision table together maintaining relative spacing; dynamic range mapping ensures no dead zones
  4. Spread controls unison (all same subdivision) to polyrhythmic (maximum separation); Spread=0.5 reproduces dropdown selections
  5. Rotate performs Euclidean circular permutation of subdivision assignments across the 4 echo paths
  6. dAPF1 and dAPF2 have independent Sync/Free toggle with per-register dropdown -- no Sweep/Spread/Rotate macros
  7. BPM changes auto-update all Sync-mode registers to their current effective subdivision's new sample count
**Plans:** 2 plans
Plans:
- [x] 22-01-PLAN.md -- API contracts + state + Sync/Free toggle + diffusion snap (header, sorted table, toggle transitions, diffusion complete)
- [x] 22-02-PLAN.md -- Discrete transforms + BPM integration (Sweep/Spread/Rotate implementation, composite apply, auto-resnap)

### Phase 23: GUI Overlay + Display
**Goal**: The JUCE GUI presents the Room Designer and macro controls as the default view, with raw registers behind an Advanced toggle, human-readable units on all controls, link/constrain toggles, and safety constraints enforced on both surfaces
**Depends on**: Phase 22
**Requirements**: GUI-01, GUI-02, GUI-03, GUI-04, GUI-05, SAFE-05, UNIT-01, UNIT-02
**Success Criteria** (what must be TRUE):
  1. Launching SPU-94 shows the Room Designer / macro panel by default -- wall controls, tap positions, diffusion section, Decay/Reflectivity, Early Reflections, Buffer; no raw register sliders visible until Advanced is toggled
  2. Toggling Advanced reveals the raw register sliders underneath; toggling back hides them -- safety constraints (stability ceiling, vIIR floor, address bounds) apply to both surfaces
  3. Wall controls show paired distance + echo speed with link toggles; same/cross link toggle available; Diffusion section shows Amount, Texture, Position with Spread+Sweep knobs and constrained/unconstrained toggle
  4. Macro knobs display human-readable units: Room Size in meters/feet, echo speeds in ms, Decay and Reflectivity in %, Diffusion in %
  5. vLIN/vRIN/vLOUT/vROUT are not visible on any GUI surface -- they are set by presets but hidden because the mixer already controls input/output levels
**UI hint**: yes
**Plans:** 4 plans
Plans:

- [x] 23-02-PLAN.md -- MacroPanel component (22 rotary knobs, 8 toggles, 6 dropdowns, unit labels, layout)
- [x] 23-03-PLAN.md -- RegisterPanel modifications (hide vLIN/vRIN/vLOUT/vROUT, dual hex+human readout)
