**3. PluginProcessor.cpp changes:**

In `processBlock`, change the `midiMessages` parameter from `/*midiMessages*/` to `midiMessages` (remove the comment-out). The function signature becomes:

void SPU94AudioProcessor::processBlock(juce::AudioBuffer<float>& buffer,

In the tempo push block inside processBlock, BEFORE the `if (mode != 0)` check, add MIDI clock processing that only runs in EXT mode:
```cpp
// MIDI clock processing (EXT mode only, per D-03)
if (mode == static_cast<uint8_t>(SyncMode::EXT)) {
    for (const auto metadata : midiMessages) {
        auto msg = metadata.getMessage();
        if (msg.isMidiClock()) {
            double now = juce::Time::getMillisecondCounterHiRes() * 0.001;
            if (lastClockTime > 0.0) {
                double interval = now - lastClockTime;
                // Sanity guard: ignore intervals > 1 second (clock restart)
                // or < 1ms (spurious double-trigger)
                if (interval > 0.001 && interval < 1.0) {
                    clockIntervals[clockIdx] = interval;
                    clockIdx = (clockIdx + 1) % kClockWindowSize;
                    if (clockCount < kClockWindowSize) clockCount++;

                    // Compute moving average
                    double sum = 0.0;
                    for (int i = 0; i < clockCount; i++) sum += clockIntervals[i];
                    double avgInterval = sum / clockCount;

                    // 24 clocks per quarter note
                    double quarterNoteSec = avgInterval * 24.0;
                    if (quarterNoteSec > 0.0) {
                        uint16_t derivedBpm = static_cast<uint16_t>(
                            60.0 / quarterNoteSec + 0.5);
                        if (derivedBpm >= 1 && derivedBpm <= 999)
                            tempoBpm.store(derivedBpm, std::memory_order_relaxed);
                    }
                }
            }
            lastClockTime = now;
        }
    }
}
```

Also add MIDI clock state reset when leaving EXT mode. In the `else if (lastPushedMode != 0)` block (transition from synced to FREE), add:

**Key design note (per RESEARCH.md Pitfall 3 - resnap avoidance):**
The MIDI-derived BPM is stored to the `tempoBpm` atomic. The processBlock tempo push code (from Plan 02) already gates `spu94_set_tempo` calls on `bpm != lastPushedBpm`. Since MIDI clock jitter smoothing produces stable BPM values (moving average over 24 samples = 1 quarter note), resnap only occurs when the tempo actually changes by at least 1 BPM.
