/* Parse an unsigned decimal integer (0-65535). Returns 0 on invalid input. */
static uint16_t parse_uint16(const char *s)
{
    if (!s) return 0;
    uint32_t val = 0;
    int digits = 0;
    for (; *s >= '0' && *s <= '9' && digits < 5; s++, digits++) {
        val = val * 10u + (uint32_t)(*s - '0');
    }
    if (digits == 0 || val > 65535u) return 0;
    return (uint16_t)val;
}

**CRITICAL DESIGN NOTE on ref_bpm and _bind restoration:**

The loader cannot fully restore proportional binding state via the existing public API alone. `spu94_set_subdivision` always sets binding to GRID. For proportional bindings, the loader needs to:
1. Parse `_bind=proportional` but NOT immediately call any binding function
2. Parse `_sub=` and store the subdivision index
3. Parse `_ref_bpm=` and store the reference BPM

To handle this cleanly, add TWO MORE public API functions in `include/spu94/spu94.h` and `src/spu94/spu94_tempo.c`:
