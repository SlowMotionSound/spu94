Subdivision table (from src/spu94/spu94_tempo.c):
```
1/1={1,1}, 1/1.={3,2}, 1/1t={2,3}, 1/2={1,2}, 1/2.={3,4}, 1/2t={1,3},
1/4={1,4}, 1/4.={3,8}, 1/4t={1,6}, 1/8={1,8}, 1/8.={3,16}, 1/8t={1,12},
1/16={1,16}, 1/16.={3,32}, 1/16t={1,24}
```

Formula: `samples = (60 * 22050 * numerator) / (bpm * denominator)` (integer truncation)

d-prefix registers are tick-latched (D-08): call spu94_tick() before spu94_get_reg_u16() reads the active value.

Tempo register to hardware register mapping (indices 0-5 are d-prefix, 6-9 are virtual combs):
- dAPF1(0)->SPU94_REG_dAPF1, dAPF2(1)->SPU94_REG_dAPF2
- dLSAME(2)->SPU94_REG_dLSAME, dRSAME(3)->SPU94_REG_dRSAME
- dLDIFF(4)->SPU94_REG_dLDIFF, dRDIFF(5)->SPU94_REG_dRDIFF
- dCOMB1-4(6-9) are virtual combs that compute mCOMB = reference - delay_samples
