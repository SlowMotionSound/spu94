BPM tracking, these controls produce tempo-locked echo rhythms.

**GREEN phase:** Implement internal transform functions in spu94_snap.c:

`compute_spread_indices(const uint8_t *ref_sub, float spread_factor, uint8_t *out_sorted_pos)`:
- Convert ref_sub[4] (subdivision enum values) to sorted positions via subdivision_to_sorted_pos[].
- Compute centroid: mean of the 4 sorted positions (float).
- For each register: offset = sorted_pos - centroid. new_pos = centroid + offset * spread_factor.
- spread_factor = spread * 2.0 (so 0.5 maps to factor 1.0 = identity, matching Phase 21 convention per Open Question #2).
- Round to nearest integer, clamp to [0, 14].
- Store in out_sorted_pos[4].

`compute_sweep_offset(const uint8_t *spread_sorted_pos, float sweep)`:
- Find min_pos and max_pos among the 4 spread positions.
- headroom_down = min_pos (how far toward 0 = longer).
- headroom_up = 14 - max_pos (how far toward 14 = shorter).
- sweep is [0, 1] where 0.5 = center. Map: if sweep < 0.5, offset = -(headroom_down * (1.0 - sweep*2)). If sweep > 0.5, offset = headroom_up * ((sweep - 0.5) * 2). If sweep == 0.5, offset = 0.
- Round to integer. Return.

`apply_sweep_to_indices(const uint8_t *spread_sorted_pos, int sweep_offset, uint8_t *out_sorted_pos)`:
- For each register: out_sorted_pos[i] = clamp(spread_sorted_pos[i] + sweep_offset, 0, 14).

Then in `spu94_snap_apply_echo_speed`:
1. Validate state, check echo_speed_sync == 1 (return SPU94_OK if not in Sync mode).
2. Validate all snap_echo_sub[i] are valid (< SPU94_SUBDIVISION__COUNT). If any is 0xFF, use the centroid of valid ones or skip.
3. Call compute_spread_indices(state->snap_echo_sub, spread, spread_positions).
4. Call compute_sweep_offset(spread_positions, sweep) -> sweep_offset.
5. Call apply_sweep_to_indices(spread_positions, sweep_offset, final_sorted_pos).
6. (Rotate applied in Task 2 -- for now pass through final_sorted_pos unchanged when rotate=0.0).
7. Convert final_sorted_pos back to subdivision enum: final_sub[i] = subdivision_sorted_by_duration[final_sorted_pos[i]].
8. Set tempo_writing = 1, call spu94_set_subdivision for each register with final_sub[i], set tempo_writing = 0.
9. Store knob positions: snap_spread_pos = spread, snap_sweep_pos = sweep.
10. Return SPU94_OK.
