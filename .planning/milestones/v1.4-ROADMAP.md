# Milestone v1.4: Preset System

**Status:** SHIPPED 2026-05-02

## Overview

Save and load custom presets as .spu94 files -- human-readable key=value text capturing all register + mixer + DAC state -- with C core API, CLI subcommands, and JUCE GUI buttons. 259 LOC C core serializer/parser, 155 LOC CLI subcommand, JUCE Save/Load GUI with custom preset dropdown and modified-state indicator. 10/10 requirements verified including integration-level golden round-trip proof.

## Milestone Summary

**Key Decisions:**

- EMIT macro pattern for overflow-safe snprintf buffer writes
- Hand-rolled parse_hex_u16 avoids strtol/long grep-guard ban
- strchr-based key=value splitting (strtok modifies strings)
- 512-byte stack line buffer with truncation for parser line safety
- Save dialog simplified to single-step native file dialog (removed JUCE AlertWindow)
- Touch-create workaround for kdialog filename pre-fill
- File-preset audio-thread handoff via pendingPresetBuf + acquire/release atomics
