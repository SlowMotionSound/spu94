# v1.5 + v1.6 Pivot Decision

**Date:** 2026-05-05
**Decision:** Archive v1.5 (Tempo-Synced Taps) and v1.6 (Musical Controls) and start fresh with an interpolation engine approach.

## What was built

### v1.5 — Tempo-Synced Taps (Phases 16-19, shipped 2026-05-03)
BPM state, subdivision table, delay-register snapping in the C core. Preset format extension. CLI --tempo flag, JUCE BPM field and subdivision selectors, MIDI clock EXT mode. Round-trip verification.

### v1.6 — Musical Controls (Phases 20-23, incomplete)
- Phase 20: Macro engine + safety core (proportional scaling, gang clamping, stability ceiling, address bounds)
- Phase 21: Macro controls (Room Size, walls, Spread+Sweep, Decay/Reflectivity coupling, link/constrain toggles — 10 macro group tables, 16 m-prefix registers in Room Size alone)
- Phase 22: Echo speed + diffusion snap (Sync/Free toggle, subdivision transforms, Sweep/Spread/Rotate)
- Phase 23: GUI overlay (MacroPanel, atomic bridge, RegisterPanel mods — built and functional but hit blocking bugs)

## Why it was archived

The macro control approach tried to make 35 raw SPU registers individually controllable through grouped scaling, gang clamping, Spread/Sweep/Rotate transforms, and safety constraints. This created compounding complexity:

- Interlocking safety constraints (stability ceiling, address bounds, gang clamping) fighting each other
- Sync/Free modal toggle with 0xFF sentinel handling for "Global" dropdown slots caused register overwrites
- Two attempted fixes for the snap-to-0 bug were reverted — each fix introduced worse side effects
- The GUI exposed the underlying complexity rather than taming it

The fundamental issue: policing 35 registers from the outside is harder than starting from known-good states and moving between them.

## What replaces it

**Preset interpolation engine.** The 9 Sony factory presets (Half Echo → Room → Studio A → Studio B → Studio C → Hall → Space Echo → Echo → Delay) become waypoints on a single morph axis. A knob sweeps through them, linearly interpolating all registers between adjacent presets. Every intermediate state is bounded by states Sony's sound designers validated.

Key insight from analysis: each preset is a genuinely different room geometry, not the same shape at different scales. Morphing between them produces a continuously variable algorithm — from tight room through concert hall through echo/delay — without any clamping or safety logic.
