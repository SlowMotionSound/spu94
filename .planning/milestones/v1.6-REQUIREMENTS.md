## Requirements

### Phase 18: User Slots Core

| ID | Requirement | Verified |
|----|-------------|----------|
| USLOT-01 | 8 user-programmable slots at midpoint positions between Sony's 9 anchors (1/16, 3/16, 5/16, ..., 15/16) | YES |
| USLOT-02 | All-empty user slots → spu94_interp_set_morph is bit-identical to v1.5 at every input position | YES |
| USLOT-03 | A filled slot acts as a new interpolation waypoint: morph_pos == slot center → bit-identical to saved register set; positions either side interpolate linearly toward the adjacent neighbour | YES |
| USLOT-04 | spu94_interp_set_user_slot / clear / get / is_filled form the public API; misuse returns SPU94_ERR_INVALID without mutating state | YES |
| USLOT-05 | INTERP-04 bit-identity guarantee extends to filled user slots (no rounding drift at slot centre) | YES |
| USLOT-06 | User slot state is per-spu94_state instance — multi-engine consumers must mirror writes (engines[0] → engines[1] for glide path) | YES |
