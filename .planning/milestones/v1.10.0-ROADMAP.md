# Milestone v1.10.0: Voice Dynamics & Stereo Effects

**Status:** SHIPPED 2026-05-28
**Phases:** 43-55 (13 phases, 12 delivered, 2 scope changes)
**Total Plans:** 20

## Overview

Surface the raw VCA ramp architecture as a curated suite of musician-facing modulation, dynamics, and stereo effects — exploiting the PS1's unique independent L/R ramp state machines. Plus a per-voice internal mod bus for self-contained noise-driven sound design.

## Milestone Summary

**Scope Changes:**
- Phase 47 (Stereo Widener): Dropped — SPU has no native stereo decorrelation
- Phase 49 (Phase Modulator): Subsumed by Ring Mod (Phase 52) — same mechanism, bipolar sweep

**Key Decisions:**
- Retrigger lives in C core (creative extension beyond hardware, but RT-safe and sample-accurate)
- Effects are curated preconfigurations of the L/R VCA ramp state machines (not new DSP)
- Internal mod bus is a creative extension (PS1 requires separate NON voice + PMON chain; we internalize it)
- Ring Mod subsumes Phase Modulator — zero-crossing behavior works cleanly
- Five final effects: Auto-Pan, Tremolo, AM, Ring Mod, Ducking (mutually exclusive, one dropdown)
- Three sweep shapes: Triangle, Saw Up, Saw Down
- GUI: unified dropdown with adaptive controls per mode
- Pan preserved during effects via base_vol_l/r ceiling
- 8-sample anti-click ramp on saw retrigger
- FRACT mode removed (PS1 uses integer addressing only)
- Preset save/load extended with [voice], [adsr], [effects], [mod_bus] sections
- ADSR calibration: direct PS1 rate indexing, vertical faders with ms/s readout

**Issues Resolved:**
- Auto-pan R channel starting at same level as L (sweep_r.level=0 on enable)
- Auto-pan parameter changes resetting oscillation state (update shift/step directly)
- Split-output bus side limiter crushing stereo effects (reverb-only side limiting)
- GUI layout effects off-screen (two-column layout)
- Pan inaccessible during effects (base_vol ceiling formula)
- Oversized sample load freezing GUI (early bail-out before resampling)

**Issues Deferred:**
- Sidechain Duck UAT (blocked on MIDI controller)
- One-shot trigger (click to play full ADSR without holding)
- GUI cleanup: noise section organization, musical divisions for Speed encoder
- Preset extension UAT (save/load round-trip verification)

**Technical Debt Incurred:**
- Requirements tracking fell behind during execution (all checkboxes stale)
- ROADMAP.md phase checkboxes not updated during phases 52-55
