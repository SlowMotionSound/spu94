Extend the Phase 20 macro engine with Spread+Sweep dual-axis apply, bipolar apply path, reference-value storage, and expanded group enum. This is the engine foundation that all Phase 21 macro controls build on.

Purpose: The Phase 20 engine only supports single-axis unipolar [0,1] proportional scaling. Phase 21's Room Designer needs dual-axis controls (Spread adjusts ratio spacing, Sweep translates the set) and bipolar controls for signed registers (Decay, Reflectivity, Early Reflections). This plan adds those engine capabilities.

Output: Modified spu94_macro.h, spu94_macro.c, spu94_state_internal.h with new engine APIs. Two new test suites proving Spread+Sweep and bipolar behavior.

  **GREEN phase:** Implement the engine functions in spu94_macro.c.

  Add to src/spu94/spu94_macro.c:

  1. `spu94_macro_set_reference`: Validate inputs. For each member, read current register value and store in `state->macro_ref_values[group_id][i]`. Return SPU94_OK.

  2. `spu94_macro_apply_spread_sweep` (per D-01, SS-01):
     - Validate inputs. Clamp spread to [0.0, 1.0].
     - For bipolar groups (is_bipolar=1), clamp sweep to [-1.0, 1.0]. For unipolar, clamp to [0.0, 1.0].
     - Compute the group mean of reference values: `ref_mean = average of ref_values[i]`.
     - For each member i:
       - `ref_offset = ref_value[i] - ref_mean` (distance from mean in reference snapshot)
       - `spread_factor = spread * 2.0f` (so spread=0.5 gives factor=1.0, reproducing reference offsets)
       - `spread_value = ref_mean + ref_offset * spread_factor` (apply spacing)
     - Compute sweep offset:
       - For unipolar: `sweep_offset = (sweep - 0.5f) * 2.0f * sweep_headroom` where sweep_headroom is computed as the maximum uniform shift before any member hits floor or ceiling from its spread position.
       - For bipolar: `sweep_offset = sweep * sweep_headroom` (sweep is already centered at 0).
     - `final_value[i] = spread_value[i] + sweep_offset`
     - Gang-clamp: compute the maximum safe sweep_offset such that no member exceeds floor or ceiling after spread, then use that as the actual offset.
     - Set macro_writing=1, iterate members, write via write_member_value, track worst result, set macro_writing=0.
     - Store spread and sweep in `state->macro_spread_pos[group_id]` and `state->macro_sweep_pos[group_id]`.
     - Store the unipolar-equivalent knob_pos for backward compat with Phase 20 get_range.

  3. `spu94_macro_apply_bipolar` (per D-19, D-22, D-30):
     - Validate inputs. Clamp position to [-1.0, 1.0].
     - Group must have exactly 1 member (single-register bipolar control).
     - Compute value:
       - If position >= 0: `value = (int32_t)(position * (float)member.ceiling + 0.5f)` (right half: 0 to ceiling)
       - If position < 0: `value = (int32_t)(position * (float)(-member.floor) + 0.5f)` (left half: maps [-1,0] to [floor,0])
       - Note: for Decay, floor=-0x1000, so left half maps [-1,0] to [-0x1000, 0]. For Reflectivity, floor=-0x8000, so left half maps [-1,0] to [-0x8000, 0].
     - Clamp to [floor, ceiling] as safety net.
     - Set macro_writing=1, write via write_member_value, set macro_writing=0.
     - Store position in `state->macro_knob_pos[group_id]`.

  4. `spu94_macro_derive_spread_sweep`:
     - Validate inputs.
     - Read current register values.
     - Compute ref_mean from macro_ref_values.
     - For spread: compute the ratio of current spacing to reference spacing. If reference spacing is zero, spread=0.5 (center). Otherwise, spread = (current_mean_distance / ref_mean_distance) / 2.0. Clamp to [0,1].
     - For sweep: compute the mean offset of current values from where spread alone would place them. Map to [0,1] or [-1,1] based on is_bipolar.
     - Write out_spread, out_sweep. Store in state arrays.

  5. `spu94_macro_derive_bipolar`:
