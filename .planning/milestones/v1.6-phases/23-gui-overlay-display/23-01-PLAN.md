Expand PluginProcessor with the full atomic bridge for macro controls -- knob positions, toggles, snap dropdowns, derived positions, and the processBlock logic that reads these atomics and calls the C core macro/snap API. This is the lock-free thread boundary between the GUI (Plans 02/04) and the audio engine.

Purpose: Every macro knob drag in the GUI must cross the thread boundary via atomics before the audio thread can call spu94_macro_apply_*. Without this bridge, the MacroPanel would have no way to affect the reverb engine.
