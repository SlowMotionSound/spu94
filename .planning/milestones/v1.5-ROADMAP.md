## Key Accomplishments

1. Preset interpolation engine: maps a morph position (0.0-1.0) to linearly interpolated register values across 9 Sony factory presets with bit-identical output at exact waypoint positions
2. MorphPanel GUI component: 280px rotary knob with 9 PS1-colored waypoint dots, detent snap at each preset, dynamic label showing preset names at detents and numerical position between
3. Macro/Advanced toggle: default morph knob view with switchable raw register access
4. Write-on-change optimization: morph engine only writes registers when position changes, preventing delay-line disruption

## Known Issues at Ship

1. Transition artifacting — digital clicks when d/m delay-line addresses change during knob movement (needs slew filter)
2. Unstable feedback at certain interpolated positions between waypoints (needs stability mapping)

## Decisions Made

- Waypoint order: Half Echo → Room → Studio A → Studio B → Studio C → Hall → Space Echo → Echo → Delay (perceptual, confirmed by ear)
- All registers morph together — no decoupled parameters for v1.5
- Fixed registers excluded from interpolation: vLOUT/vROUT (0x7FFF), vLIN/vRIN (0x8000), mBASE (0x0000)
- Simple detent snap (threshold 0.01), no magnetic physics for v1.5
- morphActive atomic gates morph engine vs register bridge in processBlock
- Equal angular spacing between waypoints on the knob arc
