## Critical Anti-Patterns

| Pattern | Description | Severity |
|---------|-------------|----------|
| Off-screen GUI placement | Repeatedly stacked controls below visible area. Use right half of sampler panel (x=410+, y < 900). | blocking |
| Non-native DSP | Added M/S width boost to a PS1-faithful project. All effects must use native SPU mechanisms. Flag departures BEFORE implementing. | blocking |
| Promising impossible features | Designed stereo widener without verifying SPU has a mechanism for it. Validate physical feasibility against SPU architecture first. | advisory |
| Per-block depth scaling | processBlock depth writes get overwritten by voice_mixer_tick per-sample. Depth must live in the C core (sweep_depth_l/r fields). | blocking |
