# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure during this session.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **Do not sum two coherent reverbs** — this session re-confirmed (twice) that two near-identical reverbs on identical input produce comb filtering by definition. Shared memory, readonly slaves, dual engines with the same inputs — none of it works. If layered character is wanted, accept the comb as a sound. If clean morph is wanted, use one engine. Decorrelating the inputs (different EQ, predelay) defeats the morph idea.

**Do not proceed with any "blend two reverbs" idea until this constraint is internalized.**

The lesson: the slew machinery does its job. Further morph-feel improvements need to attack a different surface — likely the audio output during the morph (filter sweep, wet duck, dry-wet ramp).
