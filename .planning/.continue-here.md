3. Volume Sweep — automatic per-voice volume ramp
4. Signed Volume / Phase Inversion — negative volume for phase flip
5. ENDX (Voice Status) — flags for one-shot sample completion
6. SPU IRQ — interrupt on voice reading specific RAM address
7. CD/External Input Mixing — stereo line-in at master mixer
8. Master Volume Sweep — global volume ramp

<decisions_made>

- "Patina" naming eliminated everywhere — user never liked it, ADPCM is the correct name
- Encode rate default is 22050 Hz (PS1 workhorse rate)
- No preset back-compat needed for old patina_* field names (no existing files use them)
- ~/.config/SPU-94.settings stores JUCE session state and overrides code defaults on relaunch
- PS1 devs stuck to standard rates (44100/22050/11025/5512) — dropdown, not continuous knob
- Rate selector is a pre-encode step (resample before ADPCM encode), authentic to PS1 dev workflow
- Sampler voice output does NOT pass through ADPCM path again before reverb — direct to send sum
</decisions_made>
