## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Missing SPU signal chain components | ADPCM was implemented in isolation without the downsample + Gaussian interpolation that surrounds it on real hardware. Produced audible mid-high distortion. | blocking | Before implementing any SPU component, map the COMPLETE signal chain it lives in from psx-spx. Cross-check against DuckStation source. Never implement a stage without its neighbors. |
| Dual-counter voice path (non-faithful) | Used two separate phase accumulators (decim_counter + gauss_counter) instead of the PS1's single pitch counter. Produced 98%+ sample divergence from hardware-faithful architecture. | blocking | The PS1 SPU uses ONE pitch counter per voice. Bits 12+ = sample index, bits 4-11 = Gaussian interpolation index. Never split these into independent state. See .planning/research/DEEP-SPU-VOICE-PATH.md. |
| Adding textbook-DSP corrections without flagging | Added an AA filter before decimation because "decimation needs AA filtering" — standard DSP but NOT what the PS1 does. The real hardware has no AA filter at that stage. | blocking | Default signal path must match real PS1 hardware exactly. If something seems "missing" from the spec (no AA filter, no dither, truncation), it's probably intentional — it IS the sound. Flag departures in conversation before implementing. |
| Substituting own estimates for user-provided values | Anthony said 950px, I used 700px. Three times. | advisory | When the user gives a specific number, use it exactly. |
