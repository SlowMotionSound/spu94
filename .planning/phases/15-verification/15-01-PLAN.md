**File structure:**

1. **Includes:** `unity.h`, `spu94/spu94.h`, `spu94/spu94_register_facade.h`,
   `stdalign.h`, `stdint.h`, `string.h`, `stdio.h`, `stdlib.h` (for abs).

2. **Two independent engine state sets:**
   - Engine A: `alignas(SPU94_STATE_ALIGN_MAX) unsigned char state_buf_a[SPU94_STATE_SIZE_MAX]`,
     `unsigned char work_buf_a[256 * 1024]` (256KB, matching test_preset_nonzero_tail.c),
     `spu94_state *engine_a`.
   - Engine B: same pattern with `_b` suffix.
   - A `char preset_buf[SPU94_PRESET_BUF_SIZE]` for serialization.

3. **Deterministic noise generator** -- copy the exact LCG from test_preset_nonzero_tail.c:
   ```c
   static uint32_t lcg_seed;
   static int16_t noise_sample(void) {
       lcg_seed = lcg_seed * 1103515245u + 12345u;
       const int32_t v = (int32_t)(lcg_seed >> 16) & 0xFFFF;
       return (int16_t)(v - 32767);
   }
   static void reseed(void) { lcg_seed = 0x00C0FFEE; }
   ```

4. **Helper function `drive_and_collect`:**
   ```c
   static void drive_and_collect(spu94_state *engine,
                                  int16_t *out_L, int16_t *out_R,
                                  int feed_samples, int flush_samples)
   ```
   - Reseeds the LCG (calls `reseed()`).
   - Feeds `feed_samples` of deterministic noise through `spu94_process`
     (one sample at a time: `spu94_process(engine, &Lin, &Rin, &Lout, &Rout, 1)`),
     storing each `Lout`/`Rout` into `out_L[i]`/`out_R[i]`.
   - Then flushes `flush_samples` via `spu94_flush(engine, &Lout, &Rout, 1)`,
     storing output into `out_L[feed_samples + i]`/`out_R[feed_samples + i]`.
   - Total output length: `feed_samples + flush_samples`.

5. **Helper function `configure_engine_a_factory`:**
   - `spu94_reset(engine_a)`
   - `spu94_load_preset(engine_a, SPU94_PRESET_HALL)`
   - `spu94_set_vLOUT(engine_a, (int16_t)0x7FFF)` and `spu94_set_vROUT` likewise
   - `spu94_set_input_gain(engine_a, 0x7FFF)`, `spu94_set_dry_fader(engine_a, 0x7FFF)`,
     `spu94_set_reverb_fader(engine_a, 0x7FFF)`, `spu94_set_dry_send(engine_a, 0x7FFF)`
   - `spu94_tick(engine_a)` to commit pending registers.
   This matches the pattern from test_preset_nonzero_tail.c that ensures
   non-zero output from factory presets under wet-only wiring.

6. **Helper function `configure_engine_a_custom`:**
   - `spu94_reset(engine_a)`
   - `spu94_load_preset(engine_a, SPU94_PRESET_DELAY)` -- different base than Hall
   - `spu94_set_vLOUT(engine_a, (int16_t)0x7FFF)` and `spu94_set_vROUT` likewise
   - Custom mixer faders (all non-default):
     `spu94_set_input_gain(engine_a, 0x4000)`,
     `spu94_set_dry_fader(engine_a, 0x2000)`,
     `spu94_set_patina_fader(engine_a, 0x1000)`,
     `spu94_set_dry_send(engine_a, 0x3000)`,
     `spu94_set_patina_send(engine_a, 0x0800)`,
     `spu94_set_reverb_fader(engine_a, 0x6000)`,
     `spu94_set_latency_comp(engine_a, 0)`
   - Flipped DAC toggles (all non-default):
     `spu94_set_dac_enabled(engine_a, 1)`,
     `spu94_set_dac_fir_enabled(engine_a, 0)`,
     `spu94_set_dac_noise_enabled(engine_a, 1)`,
     `spu94_set_dac_true_oversample(engine_a, 0)`
   - `spu94_tick(engine_a)` to commit.

7. **setUp/tearDown:**
   - `setUp`: init both engines via `spu94_init`, assert not null.
   - `tearDown`: set both pointers to NULL.

8. **Test constants:**
   ```c
   #define FEED_SAMPLES  2048
   #define FLUSH_SAMPLES 1024
   #define TOTAL_SAMPLES (FEED_SAMPLES + FLUSH_SAMPLES)
   ```
   2048 feed samples is enough to prime the reverb network (well within Hall's
   longest delay tap of ~9088 samples at 44.1 kHz). 1024 flush samples captures
   tail. Total = 3072 samples per channel.

   Output buffers: `static int16_t out_a_L[TOTAL_SAMPLES], out_a_R[TOTAL_SAMPLES]`,
   same for `_b`.

9. **Test 1: `test_golden_roundtrip_factory_hall`** (static void)
   - Call `configure_engine_a_factory()`.
   - Call `drive_and_collect(engine_a, out_a_L, out_a_R, FEED_SAMPLES, FLUSH_SAMPLES)`.
   - Sanity check: assert `max(abs(out_a_L[i]))` across all TOTAL_SAMPLES is > 0
     (proves engine A actually produced audio; catches silent-output regression).
   - Save: `int saved = spu94_preset_save(engine_a, "GoldenHall", "factory roundtrip", preset_buf, sizeof preset_buf)`.
     Assert `saved > 0`.
   - Init engine B fresh: `spu94_reset(engine_b)`.
   - Load: `spu94_result_t lr = spu94_preset_load(engine_b, preset_buf, (size_t)saved)`.
     Assert `lr == SPU94_OK`.
   - Tick: `spu94_tick(engine_b)` to commit loaded registers.
   - Drive engine B with identical noise: `drive_and_collect(engine_b, out_b_L, out_b_R, FEED_SAMPLES, FLUSH_SAMPLES)`.
   - Compare sample-by-sample:
     ```c
     char msg[128];
     for (int i = 0; i < TOTAL_SAMPLES; i++) {
         snprintf(msg, sizeof msg, "L sample %d: engine_a=%d engine_b=%d", i, out_a_L[i], out_b_L[i]);
         TEST_ASSERT_EQUAL_INT16_MESSAGE(out_a_L[i], out_b_L[i], msg);
         snprintf(msg, sizeof msg, "R sample %d: engine_a=%d engine_b=%d", i, out_a_R[i], out_b_R[i]);
         TEST_ASSERT_EQUAL_INT16_MESSAGE(out_a_R[i], out_b_R[i], msg);
     }
     ```

    - Save: `spu94_preset_save(engine_a, "GoldenCustom", "custom roundtrip", preset_buf, sizeof preset_buf)`.
      Assert `saved > 0`.
    - Reset engine B: `spu94_reset(engine_b)`.
    - Load + tick engine B.
    - Drive engine B with identical noise.
    - Compare sample-by-sample (same loop as test 1).

11. **main:**
    ```c

    ```
