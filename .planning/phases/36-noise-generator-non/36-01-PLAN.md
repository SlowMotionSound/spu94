<objective>
Implement the PS1 SPU global LFSR noise generator and wire it into the voice pipeline so NON-enabled voices output noise instead of ADPCM/Gaussian interpolation output.

Purpose: The noise generator is a core PS1 SPU feature used for percussion, hi-hats, wind, and textural effects. It is a single global 16-bit LFSR shared by all 24 voices, with frequency controlled by SPUCNT register fields (not per-voice pitch). ADSR still shapes the noise, and ADPCM decode still runs for side effects.

Output: Working noise generator module, integrated into voice pipeline, with TDD regression tests covering all 8 code requirements (NON-01 through NON-08).
</objective>

  <behavior>
    NON-01: LFSR with seed=1, taps at bits 15,12,11,10 XOR 1 produces deterministic sequence.
            After 1 tick with timer underflow: level shifts left, parity bit inserted as bit 0.
            Parity formula: ((lvl>>15) ^ (lvl>>12) ^ (lvl>>11) ^ (lvl>>10) ^ 1) & 1.
    NON-02: Timer decrements by step (4-7). On underflow (timer < 0), shift LFSR + reload.
            If still negative after first reload, reload again (double-reload) WITHOUT re-shifting.
            Reload value = 0x20000 >> shift.
    NON-03: Different shift/step values produce different LFSR update rates. Per-voice pitch has zero effect on noise output.
    NON-04: NON bitmask selects which voices output noise. non_flags bit N = voice N uses noise.
    NON-05: Two NON-enabled voices produce identical output samples within the same tick.
    NON-06: ADPCM decode runs for NON voices. ENDX flag fires on loop-end blocks. Loop mechanics work.
    NON-07: ADSR envelope applies to noise: gauss_out = noise_level, then adsr_level multiplied in Step 2.5.
    NON-08: Noise generator ticks once in mixer_tick before voice loop. Not per-voice.
  </behavior>
