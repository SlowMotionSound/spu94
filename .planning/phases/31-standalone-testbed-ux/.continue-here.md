<context>
The waveform display component (WaveformDisplay.h) is header-only and uses JUCE's AudioThumbnail for rendering. Markers are painted as colored vertical lines with letter labels. Dragging is handled via mouseDown/mouseDrag/mouseUp with a hit-test radius of 6px. Positions are normalized 0.0-1.0, converted to block-aligned byte addresses (16-byte ADPCM blocks) via posToBlockAddr() in the processor.

The end_addr field in spu94_voice_t is set to 0 by default (meaning no limit — use loop flags). When non-zero, the voice tick checks current_addr against it after each block decode and stops the voice if reached. This coexists with the existing loop flag mechanism from Phase 29.

The loop marker is already in the WaveformDisplay code but hidden behind the loopMode bool. Enabling it requires: a toggle button in the sampler window, wiring loopMode to the display, and mapping the loop marker position to the ADPCM loop-start address in voice RAM. The Phase 29 loop mechanism uses flag bytes in the encoded ADPCM data, so the loop point either needs to re-stamp the flag bytes or use a separate loop_addr override.
</context>
