- Window layout: sampler window left, reverb window right on launch. XWayland size guard on sampler window. Removed double centreWithSize hack.

- Latch toggle: click-to-start/click-to-stop mode alongside existing gate (hold) behavior. Enables hands-free loop audition.
- Marker Lock toggle: freezes relative distances between Start/Loop/End markers. Dragging any one moves all three as a scanning window.
- Waveform zoom/scroll: mouse wheel zooms centered on cursor, drag on empty space pans, double-click resets to full view. Zoom level indicator in top-right.
- Zoom-scaled marker knobs: delta interception — encoder feel unchanged, but marker travel scales with view span (factor 0.125). JUCE's built-in slider sensitivity APIs didn't work reliably for rotary knobs.

<decisions_made>

- ADPCM state cache at load time — pre-decode all blocks to capture correct decoder history per block boundary
- End-addr loop keeps has_block=1 — the aggressive reset (has_block=0, decode_buf_pos=0) was discarding the just-decoded block, producing DC on short loops. Now matches the VAG flag loop path.
- Block 0 silence is expected content — ADPCM starts from zero history; first block of samples with lead-in silence decodes to zeros. Not an engine bug.
- Trigger latch via toggle — gate (hold) remains default, latch enables click-on/click-off
- Marker Lock freezes offsets — captures loopOffset and endOffset relative to start when engaged
- Delta interception at 0.125 factor — multiply raw knob delta by viewSpan * 0.125 before applying to marker position
</decisions_made>
