Signed registers (I16 type, v-prefix) that interpolate:
  vIIR, vCOMB1, vCOMB2, vCOMB3, vCOMB4, vWALL, vAPF1, vAPF2
  -- these are signed Q15 coefficients. Several presets have negative values
  (e.g., vCOMB2 = 0xBCE0 = -17184, vWALL = 0x8500 = -31488).
  Interpolation MUST treat these as int16_t (signed) to avoid wraparound
  through the unsigned range.

Unsigned registers (U16 type, d-prefix/m-prefix) that interpolate:
  dAPF1, dAPF2, mLSAME, mRSAME, mLCOMB1, mRCOMB1, mLCOMB2, mRCOMB2,
  dLSAME, dRSAME, mLDIFF, mRDIFF, mLCOMB3, mRCOMB3, mLCOMB4, mRCOMB4,
  dLDIFF, dRDIFF, mLAPF1, mRAPF1, mLAPF2, mRAPF2
  -- these are unsigned delay-line offsets / buffer addresses.
  Interpolation treats as uint16_t (all values are positive).

**1. Add declaration to `include/spu94/spu94.h`**

Before the `#ifdef __cplusplus` closing brace, add a new section:

```c
/* ------------------------------------------------------------------------- */
/* Preset interpolation engine (Phase 16, INTERP-01..05)                     */
/* ------------------------------------------------------------------------- */

/* Number of waypoints in the morph continuum. The order is perceptual
 * (confirmed by ear), not the spu94_preset_id_t enum order:
 *   0: Half Echo, 1: Room, 2: Studio A, 3: Studio B, 4: Studio C,
 *   5: Hall, 6: Space Echo, 7: Echo, 8: Delay.                              */
#define SPU94_INTERP_WAYPOINT_COUNT 9

/* Set the morph position and write interpolated register values to state.
 *
 * position: 0.0 = first waypoint (Half Echo), 1.0 = last (Delay).
 *           Clamped to [0.0, 1.0]. Values outside this range are safe.
 *
 * At each of the 9 waypoint positions (0/8, 1/8, ... 8/8), the written
 * registers are bit-identical to the corresponding Sony factory preset
 * (INTERP-04 -- no rounding drift).
 *
 * Between waypoints, all 30 active registers are linearly interpolated
 * (INTERP-02). The 5 fixed registers are always written as their constant
 * values: vLOUT/vROUT = 0x7FFF, vLIN/vRIN = 0x8000, mBASE = 0x0000
 * (INTERP-03).
 *
 * Signed registers (v-prefix coefficients) interpolate in their signed
 * int16 range (INTERP-05 -- no unsigned wraparound).
 *
 * Writes use the engine-layer setters (spu94_set_reg_i16/u16), so the
 * split write-timing policy (ADR-0005) is honored automatically:
 * v-prefix gains take effect immediately, d/m-prefix addresses stage
 * to pending and commit at the next spu94_tick.
 *
 * NULL state is a no-op. */
void spu94_interp_set_morph(spu94_state *state, float position);
```

**2. Create `src/spu94/spu94_interp.c`**

Implement with the following structure:

a) **Waypoint table** -- a static const array of 9 `spu94_preset_id_t` values
in the perceptual order:
```c
static const spu94_preset_id_t spu94_interp_waypoints[SPU94_INTERP_WAYPOINT_COUNT] = {
    SPU94_PRESET_HALF_ECHO,
    SPU94_PRESET_ROOM,
    SPU94_PRESET_STUDIO_A,
    SPU94_PRESET_STUDIO_B,
    SPU94_PRESET_STUDIO_C,
    SPU94_PRESET_HALL,
    SPU94_PRESET_SPACE_ECHO,
    SPU94_PRESET_ECHO,
    SPU94_PRESET_DELAY
};
```

b) **Fixed register check** -- a small helper or inline check. A register is
"fixed" if it is vLOUT, vROUT, vLIN, vRIN, or mBASE.

c) **spu94_interp_set_morph implementation:**

1. NULL-guard: `if (!state) return;`

2. Clamp position to [0.0f, 1.0f].

3. Map position to segment index and fractional distance:
   ```c
   float scaled = position * (SPU94_INTERP_WAYPOINT_COUNT - 1); /* 0..8 */
   int seg = (int)scaled;                /* segment index 0..7 (or 8 at endpoint) */
   float frac = scaled - (float)seg;     /* fractional distance within segment */
   /* Clamp segment to valid range (handles position == 1.0 exactly) */
   if (seg >= SPU94_INTERP_WAYPOINT_COUNT - 1) {
       seg = SPU94_INTERP_WAYPOINT_COUNT - 2;  /* last valid segment = 7 */
       frac = 1.0f;
   }
   ```

4. Get pointers to the two adjacent preset register arrays:
   ```c
   const int16_t *a = spu94_presets[spu94_interp_waypoints[seg]].regs;
   const int16_t *b = spu94_presets[spu94_interp_waypoints[seg + 1]].regs;
   ```

5. Loop over all 35 registers. For each register r:

   - If r is a fixed register, write the fixed value and continue:
     - vLOUT/vROUT: `spu94_set_reg_i16(state, r, 0x7FFF);`
     - vLIN/vRIN: `spu94_set_reg_i16(state, r, (int16_t)0x8000);`
     - mBASE: `spu94_set_reg_u16(state, r, 0x0000);`

   - **Critical for INTERP-04 (waypoint identity):** When frac == 0.0f,
     write `a[r]` directly (no interpolation math). When frac == 1.0f,
     write `b[r]` directly. This avoids any floating-point rounding drift
     at exact waypoint positions.

   - Otherwise, interpolate based on register type:

     For I16 (signed) registers:
     ```c
     int16_t va = a[r];
     int16_t vb = b[r];
     int32_t interp = (int32_t)va + (int32_t)((float)(vb - va) * frac);
     /* Clamp to int16 range (safety -- should never trigger with Sony presets) */
     if (interp > 32767) interp = 32767;
     if (interp < -32768) interp = -32768;
     spu94_set_reg_i16(state, r, (int16_t)interp);
     ```

     For U16 (unsigned) registers:
     ```c
     uint16_t va = (uint16_t)a[r];
     uint16_t vb = (uint16_t)b[r];
     /* Use int32 to handle the subtraction safely (vb could be < va) */
     int32_t interp = (int32_t)va + (int32_t)((float)((int32_t)vb - (int32_t)va) * frac);
     if (interp > 65535) interp = 65535;
     if (interp < 0) interp = 0;
     spu94_set_reg_u16(state, r, (uint16_t)interp);
     ```

   The key insight for INTERP-05: the signed path uses `int16_t` arithmetic,
   so negative values like vCOMB2 = 0xBCE0 = -17184 are handled correctly.
   The unsigned path uses `uint16_t` reinterpretation for d/m-prefix registers
   which are always positive addresses.
