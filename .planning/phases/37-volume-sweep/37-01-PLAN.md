<objective>
Extract the counter-accumulate envelope stepping math from spu94_adsr.c into a shared helper function spu94_envelope_step(), then refactor all four ADSR phases to call it.

Purpose: The PS1 SPU uses the identical counter-accumulate mechanism for both ADSR envelopes and volume sweep. Extracting it into a shared helper guarantees bit-identical behavior between the two and prevents the divergence pitfall (Pitfall 1 from RESEARCH.md). Volume sweep (Plan 02) will call this same helper.

Output: spu94_envelope_step.h/.c with the shared helper; spu94_adsr.c refactored to use it; all existing ADSR tests passing bit-identically.
</objective>

  <name>Shared Envelope Step Helper</name>
  <files>include/spu94/spu94_envelope_step.h, src/spu94/spu94_envelope_step.c, src/spu94/spu94_adsr.c, src/spu94/CMakeLists.txt</files>
  <behavior>
    ADSR refactored to call shared helper:
    - All 12 existing ADSR tests produce bit-identical results (golden-file regression gate)
    - Attack phase: calls helper with decrease=0, exponential=attack_exp, phase_negative=0
    - Decay phase: calls helper with decrease=1, exponential=1, step_index=0 (base 8), phase_negative=0
    - Sustain increase: calls helper with decrease=0, exponential=sustain_exp, phase_negative=0
    - Sustain decrease: calls helper with decrease=1, exponential=sustain_exp, phase_negative=0
    - Release: calls helper with decrease=1, exponential=release_exp, step_index=0 (base 8), phase_negative=0
    - Phase transitions (ATTACK->DECAY, DECAY->SUSTAIN, SUSTAIN->RELEASE, RELEASE->OFF) remain in spu94_adsr_tick, NOT in the shared helper
    
    Shared helper contract:
    - Input: pointer to envelope state (level + counter), shift, step_index, decrease, exponential, phase_negative flags
    - Output: modifies level and counter in place; returns 1 if step was applied, 0 if not
    - For increase: base_step = (7 - step_index) << max(0, 11 - shift) (SWEEP-03 positive)
    - For decrease: base_step = -(8 - step_index) << max(0, 11 - shift) (SWEEP-03 negative, per ADR-0056)
    - Anti-stall guard: if exponential decrease and scaled_step == 0 and level > 0 then scaled_step = -1
    - Fake exponential increase: if exponential and !decrease and level > 0x6000 then counter_increment >>= 2
    - Phase_negative: inverts step sign (for sweep only; ADSR always passes 0)
    - Clamping: helper does NOT clamp; caller (ADSR or sweep) handles boundary logic
  </behavior>
