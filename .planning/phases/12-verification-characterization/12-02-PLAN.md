Create tools/dac_compare.py -- a script that renders the same input through v1.2 and v1.3 DAC modes and produces 4 comparison measurements with plots.

Structure (follow tools/dac_measure.py conventions):
```python
#!/usr/bin/env python3
"""tools/dac_compare.py -- Phase 12 (CMP-02)

v1.2 vs v1.3 DAC characterization comparison. Produces 4 measurements:
  1. Frequency response: transfer function overlay (v1.2 vs v1.3)
  2. Impulse response: time-domain impulse difference
  3. Noise floor: PSD comparison (silence input, noise-only)
  4. Time-domain: waveform overlay on music-like signal (chirp)

Usage:
  python3 tools/dac_compare.py           Run measurements, print summary
  python3 tools/dac_compare.py --plot    Also generate tools/dac_compare.png
  python3 tools/dac_compare.py --verbose Print detailed diagnostics
"""
```

Implementation details:

1. **locate_cli()** -- reuse same pattern as dac_measure.py (SPU94_BIN env, build/src/cli/spu94, PATH)

2. **render_v12(input_path, output_path, spu94_bin, no_fir=False, no_noise=False):**
   - Calls: [spu94_bin, "reverb", "--preset", "off", "--dac", "--no-dac-true-oversample", "--input-gain", "1.0", "--dry", "1.0", ...]
   - If no_fir: adds "--no-dac-fir"
   - If no_noise: adds "--no-dac-noise"

3. **render_v13(input_path, output_path, spu94_bin, no_fir=False, no_noise=False):**
   - Same but WITHOUT --no-dac-true-oversample (v1.3 is default)

4. **measure_frequency_response(spu94_bin):**
   - Generate white noise input (same seed as dac_measure.py: 0xDAC_F1B, 2 seconds, 44100 Hz)
   - Render through v1.2 with --no-dac-noise
   - Render through v1.3 with --no-dac-noise
   - Compute Welch PSD transfer function for each
   - Return (freq, v12_dB, v13_dB, max_difference_dB)

5. **measure_impulse_response(spu94_bin):**
   - Generate impulse (single sample L[0]=R[0]=16000, then silence)
   - Render through v1.2 (FIR only, no noise)
   - Render through v1.3 (FIR only, no noise)
   - Return (v12_impulse, v13_impulse, peak_diff, rms_diff)

6. **measure_noise_floor(spu94_bin):**
   - Generate silence input
   - Render through v1.2 with --no-dac-fir (noise only)
   - Render through v1.3 with --no-dac-fir (noise only)
   - Compute Welch PSD for each
   - Return (freq, v12_psd_dB, v13_psd_dB, rms_v12_dBFS, rms_v13_dBFS)

7. **measure_time_domain(spu94_bin):**
   - Generate log chirp (20-20kHz, 2 seconds, same as regenerate_goldens.py sweep)
   - Render through v1.2 (full DAC: FIR + noise)
   - Render through v1.3 (full DAC: FIR + noise)
   - Return (v12_signal, v13_signal, max_sample_diff, rms_diff_dBFS)

8. **plot_comparison(...):**
   - 4-panel matplotlib figure (2x2): freq response overlay, impulse overlay, noise floor PSD overlay, time-domain waveform difference
   - Save to tools/dac_compare.png at 150 DPI

9. **main():**
   - Run all 4 measurements
   - Print summary table with pass/info status for each:
     - Freq response: max deviation between v1.2 and v1.3 in passband (20-20kHz)
     - Impulse: peak sample difference, RMS difference
     - Noise floor: RMS level for each mode in dBFS
     - Time-domain: max sample difference, RMS difference in dBFS
   - Always exit 0 (this is a measurement script, not a pass/fail gate)
   - If --plot: generate PNG

Constants:
- FS = 44100
- DURATION = 2.0 seconds
- N_SAMPLES = 88200
- NOISE_SEED = 0xDAC_F1B (same as dac_measure.py for consistency)
- AMP = 16000 (same as regenerate_goldens.py)

The script must NOT import from dac_measure.py (standalone tool), but follows the same conventions.
