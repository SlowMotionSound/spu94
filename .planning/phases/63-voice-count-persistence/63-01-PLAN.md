<objective>
Persist the active sampler voice count (1-24) into the `.spu94` text preset format and
restore it on load, with the standalone Voice Count selector snapping to the restored
value. Pre-feature presets (no count key) load as the full 24-voice rig.

Purpose: Closes VCOUNT-04 — the last open requirement of the v1.12.0 Voice Count
milestone. The count was made live-settable in Phase 62; this phase makes it part of the
saved patch so a reloaded preset plays at the count it was saved with.

- `getActiveVoiceCount() const` acquire getter (PluginProcessor.h)

- One selector-resync line (PluginEditor.cpp)

  (`test_voice_persist` with round-trip / back-compat / clamp cases)
