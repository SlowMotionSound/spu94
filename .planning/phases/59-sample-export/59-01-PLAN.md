  <name>Task 1: WAV export method in PluginProcessor</name>
  <files>src/plugin/PluginProcessor.h, src/plugin/PluginProcessor.cpp</files>
  <action>
  Add a public method `bool exportSampleToWav(const juce::File& destFile)` to SPU94AudioProcessor.

  In PluginProcessor.h: declare it in the public section near the existing voice engine control methods (around line 64, after loadVoiceSample).

  In PluginProcessor.cpp: implement exportSampleToWav. The method:

  1. Guard: if voiceSampleLoaded is false or waveformFrames is 0, return false immediately.

  2. Read trim region: load sampleStartPos and sampleEndPos (both atomic doubles, normalized 0.0-1.0). Compute startFrame = floor(startPos * waveformFrames), endFrame = ceil(endPos * waveformFrames). Clamp both to [0, waveformFrames]. If endFrame is less than or equal to startFrame, return false.

  3. Compute trimmed frame count: numFrames = endFrame - startFrame.

  4. Read sample rate: sampleRate = encodeRate.load().

  5. Write a standard RIFF WAV file using raw binary I/O (juce::FileOutputStream). The WAV header fields:
     - RIFF chunk: "RIFF", chunkSize (36 + dataSize), "WAVE"
     - fmt subchunk: "fmt ", 16 (subchunk size), 1 (PCM format), 1 (mono), sampleRate, sampleRate * 2 (byte rate for 16-bit mono), 2 (block align), 16 (bits per sample)
     - data subchunk: "data", dataSize (numFrames * 2), then numFrames int16_t samples from waveformData starting at index startFrame

     Write all multi-byte integers as little-endian (WAV spec). Use juce::ByteOrder::swapIfBigEndian on uint32_t/uint16_t/int16_t values before writing, so this works on any platform.

  6. Return true on success, false if the file could not be created or written.

  Do NOT use juce::WavAudioFormat or juce::AudioFormatWriter -- write the 44-byte header manually. This avoids pulling in JUCE's audio format machinery for a trivial 16-bit mono PCM write, and gives explicit control over the sample rate field (per EXP-03).

  Place the implementation near the existing loadVoiceSample and encodeRecordedSample methods (around line 2220 in PluginProcessor.cpp).
