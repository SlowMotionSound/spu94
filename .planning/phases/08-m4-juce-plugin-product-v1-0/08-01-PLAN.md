  <name>Task 1: Install JUCE Linux build dependencies</name>
  <action>
Anthony needs to install the six missing system packages that JUCE 8 requires on Ubuntu 25.10. These are development headers for audio (ALSA, JACK), fonts, networking (curl -- used at compile time even though we disable it at runtime), and OpenGL.

Run this single command in a terminal:

```bash
sudo apt update && sudo apt install -y \
    libasound2-dev \
    libjack-jackd2-dev \
    libcurl4-openssl-dev \
    libfontconfig1-dev \
    libwebkit2gtk-4.1-dev \
    libglu1-mesa-dev \
    mesa-common-dev
```

What each package provides:
- libasound2-dev: ALSA audio backend (lets JUCE talk to your sound card)
- libjack-jackd2-dev: JACK audio backend (works through PipeWire's JACK compatibility layer on your system)
- libcurl4-openssl-dev: HTTP client headers (JUCE compiles against them even though we disable curl at runtime)
- libfontconfig1-dev: Font configuration (JUCE needs this for text rendering)
- libwebkit2gtk-4.1-dev: WebKit headers (JUCE compiles against them even though we disable the web browser at runtime)
- libglu1-mesa-dev + mesa-common-dev: OpenGL utility headers (JUCE links against these for its rendering pipeline)

All six are in Ubuntu's standard repositories -- no PPAs or external repos needed.

  </verify>
