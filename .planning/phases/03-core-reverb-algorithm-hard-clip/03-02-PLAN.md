<!-- Register reads needed inside these stages (TICK_LATCHED per ADR-0005): -->
SAME IIR reads: dLSAME, dRSAME (offsets for wall taps), mLSAME, mRSAME (memory-write addresses).
DIFF IIR reads: dLDIFF, dRDIFF (note: nocash swaps — dRDIFF feeds mLDIFF and dLDIFF feeds mRDIFF), mLDIFF, mRDIFF.
Registers are unsigned u16 (address-family). Read via `spu94_get_reg_u16(state, SPU94_REG_dLSAME)` etc.

Nocash pseudocode (verbatim, source: psx-spx.consoledev.net/soundprocessingunitspu/):

```
;Same Side Reflection (left-to-left and right-to-right)
[mLSAME] = (Lin + [dLSAME]*vWALL - [mLSAME-2])*vIIR + [mLSAME-2]  ;L-to-L
[mRSAME] = (Rin + [dRSAME]*vWALL - [mRSAME-2])*vIIR + [mRSAME-2]  ;R-to-R

;Different Side Reflection (left-to-right and right-to-left)
[mLDIFF] = (Lin + [dRDIFF]*vWALL - [mLDIFF-2])*vIIR + [mLDIFF-2]  ;R-to-L
[mRDIFF] = (Rin + [dLDIFF]*vWALL - [mRDIFF-2])*vIIR + [mRDIFF-2]  ;L-to-R
```

vIIR anomaly (verbatim):
> "vIIR works only in range -7FFFh..+7FFFh. When set to -8000h, the multiplication by -8000h is still done correctly, but, the final result (the value written to memory) gets negated"

<!-- Buffer arithmetic (Phase 2 Plan 04, reference): -->
Work buffer is 0x80000 bytes (524288) max per PS1 spec. Address arithmetic wraps:
  effective_byte_offset = (buffer_address + reg_byte_offset) & 0x7FFFE  (halfword-aligned)

All m*/d* registers store *halfword* indexes (nocash convention). Byte offset = reg_value * 2.
Subtract-2 in pseudocode = subtract one halfword = subtract 2 bytes.

Work buffer is `state->work_buf` with size `state->work_buf_size`. Reads/writes must additionally clamp to work_buf_size if less than 0x80000 (callers provide variable sizes; the 0x7FFFE mask gives the hardware-correct address, but the caller's buffer may be smaller — Phase 2 treats this as undefined but non-crashing; Plan 02 uses the mask and trusts the caller).

    ```c
    /* Reverb work-buffer tap helpers. Nocash register values are halfword
     * indexes; byte offset = halfword_idx * 2. The 0x7FFFE mask matches
     * Phase 2 Plan 04's buffer_advance wrap rule (byte-aligned halfword
     * ring at max 0x80000 bytes). If work_buf_size is smaller than
     * 0x80000, out-of-range reads return 0 and writes are discarded —
     * defensive; Phase 2 tests exercise the wrap corners.
     */
    static inline int16_t reverb_buf_read(const spu94_state *s,
                                          uint16_t halfword_offset)
    {
        if (s->work_buf == (unsigned char *)0) return 0;
        uint32_t byte_off = (s->buffer_address + (uint32_t)halfword_offset * 2u)
                            & 0x7FFFEu;
        if ((size_t)byte_off + 1u >= s->work_buf_size) return 0;
        /* Little-endian halfword read (matches Phase 2 buffer TU convention). */
        return (int16_t)((uint16_t)s->work_buf[byte_off]
                       | ((uint16_t)s->work_buf[byte_off + 1u] << 8));
    }

    static inline void reverb_buf_write(spu94_state *s,
                                        uint16_t halfword_offset,
                                        int16_t value)
    {
        if (s->work_buf == (unsigned char *)0) return;
        uint32_t byte_off = (s->buffer_address + (uint32_t)halfword_offset * 2u)
                            & 0x7FFFEu;
        if ((size_t)byte_off + 1u >= s->work_buf_size) return;
        uint16_t u = (uint16_t)value;
        s->work_buf[byte_off]       = (unsigned char)(u & 0xFFu);
        s->work_buf[byte_off + 1u]  = (unsigned char)((u >> 8) & 0xFFu);
    }
    ```

    ```python
    def ref_same_iir(buf: dict, Lin: int, Rin: int, vIIR: int, vWALL: int,
                     regs: dict, buffer_address: int) -> tuple:
        """Nocash E1 (verbatim):
          [mLSAME] = (Lin + [dLSAME]*vWALL - [mLSAME-2])*vIIR + [mLSAME-2]
          [mRSAME] = (Rin + [dRSAME]*vWALL - [mRSAME-2])*vIIR + [mRSAME-2]

        D-10: if vIIR == -0x8000, negate the final memory-written result.
        Returns (updated buf dict, err_accumulation)."""

        def buf_read(halfword_offset):
            byte_off = (buffer_address + (halfword_offset & 0xFFFF) * 2) & 0x7FFFE
            return buf.get(byte_off, 0)

        def buf_write(halfword_offset, value):
            byte_off = (buffer_address + (halfword_offset & 0xFFFF) * 2) & 0x7FFFE
            new_buf[byte_off] = value

        new_buf = dict(buf)
        err_total = 0

        # L side:
        dLSAME = regs['dLSAME']; mLSAME = regs['mLSAME']
        tap_d = buf_read(dLSAME)
        tap_prev = buf_read((mLSAME - 2) & 0xFFFF)

        return new_buf, err_total
    ```
