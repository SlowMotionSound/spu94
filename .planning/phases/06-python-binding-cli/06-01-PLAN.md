## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| libspu94.so ↔ Python process | Untrusted only in the adversarial-environment sense (a stale / wrong library silently loaded). Drift asserts + absolute-path loading are the mitigations. |
| env var SPU94_LIB → ctypes.CDLL | Developer-controlled; used by Phases 2–5 fuzz scripts. Not an attack surface in a dev workflow; accepted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `ctypes.CDLL(...)` library resolution | mitigate | Load by ABSOLUTE path only — `Path(__file__).parent / 'libspu94.so'` for installed wheels, or `os.environ['SPU94_LIB']` for dev. Never pass a bare filename (Pitfall 4 — linker silently loads `/usr/lib/libspu94.so` if present). |
| T-06-02 | Tampering | Struct drift (Phase 7+ adds a field past SPU94_STATE_SIZE_MAX) loaded by an old wheel | mitigate | Import-time assert `spu94_state_size() <= SPU94_STATE_SIZE_MAX`; RuntimeError with "spu94 library mismatch: spu94_state_size() = N exceeds SPU94_STATE_SIZE_MAX = M ..." on violation. |
| T-06-03 | Tampering | Register-enum drift (a future phase adds a 36th register) | mitigate | Import-time assert: iterate `spu94_reg_name(i)` for i in `0..34`, require non-NULL each; assert `spu94_reg_name(35)` returns NULL (catches "count grew"). RuntimeError with an actionable message ("Recompile the bindings") on violation. |
| T-06-04 | Tampering | Preset-table drift (presets renumbered or count changed) | mitigate | Read `spu94_presets[i].name` for i in 0..9 via `ctypes.in_dll`; assert names match the expected human-readable names; RuntimeError on mismatch naming which preset differs. |
| T-06-05 | Information Disclosure | ctypes crashes leak a Python traceback into stderr | accept | Dev-time only. The package does not catch SIGSEGV; developers expect a traceback if the library is malformed. Production consumers (Plan 2 `SPU94` class + Plan 4 wheel smoke test) don't expose raw ctypes calls. |
| T-06-06 | Denial of Service | `_reflect_registers()` runs 36 library calls at import | accept | One-time cost; import is expected to happen once per process. Measured < 5 ms on dev host. |

No V5 Input Validation threats in Plan 1 — the binding itself takes no untrusted input; Plan 2 owns numpy validation (D-09); Plan 3 owns JSON / WAV / argv validation. Plan 1's mitigations cover Plan 1's actual attack surface (library tampering / drift).

"""python/spu94/__init__.py

Phase 6 Plan 1: the Python binding entry point.

Responsibilities (IN THIS ORDER AT IMPORT TIME):
  1. Load libspu94.so by absolute path (via _binding._lib).
  2. Verify the library is self-consistent (drift asserts — D-07).
  3. Build spu94.Register IntEnum by iterating spu94_reg_name(i) (D-06).
  4. Build spu94.Preset IntEnum from spu94_presets[] via presets.py.
  5. Expose a clean public surface: _lib, Register, Preset, presets,
     SPU94_STATE_SIZE_MAX, SPU94_LATENCY_SAMPLES, result-code constants,
     self_test().

The raw-panel public functions (process, flush, init, destroy, etc.)
and the SPU94 class are DELIVERED BY PLAN 2. Plan 1 exposes only the
reflection scaffolding those depend on.
"""
from enum import IntEnum

from ._binding import (
    _lib,
    SPU94_STATE_SIZE_MAX,
    SPU94_STATE_ALIGN_MAX,
    SPU94_LATENCY_SAMPLES,
    SPU94_REG__COUNT,
    SPU94_PRESET__COUNT,
    SPU94_OK, SPU94_CLAMPED, SPU94_UNKNOWN_REG, SPU94_TYPE_MISMATCH,
)

# ----------------------------------------------------------------------
# Drift assertions (D-07, T-06-02..T-06-04)
# ----------------------------------------------------------------------

_state_size = _lib.spu94_state_size()
if _state_size > SPU94_STATE_SIZE_MAX:
    raise RuntimeError(
        f"spu94 library mismatch: spu94_state_size() = {_state_size} exceeds "
        f"SPU94_STATE_SIZE_MAX = {SPU94_STATE_SIZE_MAX}. Library is from a "
        f"future incompatible build — upgrade the Python binding."
    )

# Cache the state size for Plan 2's SPU94 class + self_test().
_STATE_SIZE = _state_size

# ----------------------------------------------------------------------
# Register IntEnum — runtime reflection (D-06)
# ----------------------------------------------------------------------

def _reflect_registers():
    """Walk spu94_reg_name(0..SPU94_REG__COUNT-1). Validate that the
    sentinel `spu94_reg_name(SPU94_REG__COUNT)` returns NULL — this
    catches "count grew" drift."""
    members = {}
    for i in range(SPU94_REG__COUNT):
        name_bytes = _lib.spu94_reg_name(i)
        if not name_bytes:
            raise RuntimeError(
                f"spu94 library mismatch: spu94_reg_name({i}) returned NULL. "
                f"Library reports fewer than SPU94_REG__COUNT={SPU94_REG__COUNT} "
                f"registers. Recompile the bindings against the live library, "
                f"or pin the library version."
            )
        members[name_bytes.decode("ascii")] = i

    sentinel = _lib.spu94_reg_name(SPU94_REG__COUNT)
    if sentinel is not None:
        raise RuntimeError(
            f"spu94 library mismatch: spu94_reg_name({SPU94_REG__COUNT}) returned "
            f"non-NULL ({sentinel!r}). Library has MORE than {SPU94_REG__COUNT} "
            f"registers. Recompile the bindings."
        )
    return IntEnum("Register", members, module=__name__)

Register = _reflect_registers()

# ----------------------------------------------------------------------
# Preset IntEnum + .presets accessor (delegated to presets.py so the
# ctypes.in_dll concern is isolated)
# ----------------------------------------------------------------------
from .presets import Preset, presets  # noqa: E402 — after Register is built

__all__ = [

import importlib
import sys
import pytest

def _reimport_spu94():
    """Remove cached spu94 modules and re-import so __init__.py re-runs
    the drift assertions with whatever patches are active."""
    for mod in ("spu94", "spu94._binding", "spu94.presets"):
        sys.modules.pop(mod, None)
    return importlib.import_module("spu94")

def test_state_size_overflow_raises(spu94_lib_path, monkeypatch):
    monkeypatch.setenv("SPU94_LIB", spu94_lib_path)
    # Patch ctypes.CDLL's spu94_state_size to return a huge value.
    import ctypes
    real_cdll = ctypes.CDLL
    class PatchedCDLL:
        def __init__(self, path):
            self._inner = real_cdll(path)
        def __getattr__(self, name):
            if name == "spu94_state_size":
                fake = lambda: spu94_module_expected_max + 1
                fake_wrap = type("F", (), {"__call__": staticmethod(fake),
                                           "restype": ctypes.c_size_t,
                                           "argtypes": []})()
                return fake_wrap
            return getattr(self._inner, name)
    spu94_module_expected_max = 16384
    monkeypatch.setattr(ctypes, "CDLL", PatchedCDLL)

"""python/spu94/presets.py

Phase 6 Plan 1 Task 3: expose the 10 factory presets as Python data (D-02).

Two surfaces:
  1. `Preset` — IntEnum of 10 members (OFF..DELAY, numeric values matching
     include/spu94/spu94.h spu94_preset_id_t).
  2. `presets` — dict-like accessor supporting:
        presets["hall"]                 (case-insensitive string)
        presets["Hall"]                 (same, via .lower())
        presets[Preset.HALL]            (enum)
        presets[5]                      (int)
        list(presets)                   (iterates 10 PresetInfo objects
                                         in preset-id order)

Data flows directly from the C `spu94_presets[]` .rodata symbol via
ctypes.in_dll — no hand-typed parallel tables in Python.
"""
import ctypes
from dataclasses import dataclass
from enum import IntEnum
from typing import Tuple, Union

from ._binding import _lib, SPU94_REG__COUNT, SPU94_PRESET__COUNT


class _CPreset(ctypes.Structure):
    _fields_ = [
        ("name", ctypes.c_char_p),
        ("regs", ctypes.c_int16 * SPU94_REG__COUNT),
    ]


# Read the extern const spu94_preset_t spu94_presets[10] symbol.
_presets_arr = (_CPreset * SPU94_PRESET__COUNT).in_dll(_lib, "spu94_presets")


# -----------------------------------------------------------------------
# Preset IntEnum — numeric values are ABI per include/spu94/spu94.h
# SPU94_PRESET_OFF=0..SPU94_PRESET_DELAY=9. We DO NOT reflect these from
# the table (the names in spu94_presets[].name are "Off", "Room",
# "Studio A", etc. with spaces — they're human-readable display names,
# not enum identifiers). We hard-code the IntEnum names to match the
# C enum identifiers (with the SPU94_PRESET_ prefix stripped, uppercase).
# Drift detection for this is a separate test: the preset at index i
# must have a name matching an expected value (see test_binding_preset_table).
# -----------------------------------------------------------------------
class Preset(IntEnum):
    OFF        = 0
    ROOM       = 1
    STUDIO_A   = 2
    STUDIO_B   = 3
    STUDIO_C   = 4
    HALL       = 5
    HALF_ECHO  = 6
    SPACE_ECHO = 7
    ECHO       = 8
    DELAY      = 9

# Drift assertion — the names in the C-side spu94_presets[] table MUST
# match the human-readable names we expect. If a future phase reorders
# or renames presets, this fires.
_EXPECTED_NAMES = [
    "Off", "Room", "Studio A", "Studio B", "Studio C",
    "Hall", "Half Echo", "Space Echo", "Echo", "Delay",
]
for i, expected in enumerate(_EXPECTED_NAMES):
    actual_bytes = _presets_arr[i].name
    if actual_bytes is None:
        raise RuntimeError(
            f"spu94 library mismatch: spu94_presets[{i}].name is NULL; "
            f"expected {expected!r}."
        )
    actual = actual_bytes.decode("ascii")
    if actual != expected:
        raise RuntimeError(
            f"spu94 library mismatch: spu94_presets[{i}].name = {actual!r}, "
            f"expected {expected!r}. Preset table has been reordered or "
            f"renamed — update python/spu94/presets.py _EXPECTED_NAMES and "
            f"coordinate with docs/DECISIONS.md."
        )


@dataclass(frozen=True)
class PresetInfo:
    """Snapshot of one factory preset. .regs is a 35-tuple of int16
    indexed by Register (e.g., .regs[Register.mBASE] reads the mBASE
    value for this preset). Immutable — represents .rodata."""
    id: int
    name: str                    # human-readable (e.g., "Hall")
    regs: Tuple[int, ...]        # length == 35


# Build the accessor — populated at module import time.
_preset_infos_by_id: dict = {}
_preset_infos_by_name: dict = {}

for i in range(SPU94_PRESET__COUNT):
    name_str = _presets_arr[i].name.decode("ascii")
    regs_tuple = tuple(_presets_arr[i].regs[j] for j in range(SPU94_REG__COUNT))
    info = PresetInfo(id=i, name=name_str, regs=regs_tuple)
    _preset_infos_by_id[i] = info
    # Also key by lowercase name without spaces → matches the CLI --preset
    # contract from Plan 3 (D-03: spu94 --preset hall). Examples:
    # "Hall" -> "hall"; "Studio A" -> "studio_a"; "Half Echo" -> "half_echo".
    normalized = name_str.lower().replace(" ", "_")
    _preset_infos_by_name[normalized] = info


class _PresetTable:
    """Dict-like accessor for the factory presets (D-02).

    Supports integer, Preset enum, case-insensitive string keys. Iteration
    yields PresetInfo objects in preset-id order.
    """
    def __getitem__(self, key: Union[int, Preset, str]) -> PresetInfo:
        if isinstance(key, Preset):
            return _preset_infos_by_id[int(key)]
        if isinstance(key, int):
            if key not in _preset_infos_by_id:
                raise KeyError(f"Preset id {key} out of range (0..9)")
            return _preset_infos_by_id[key]
        if isinstance(key, str):
            normalized = key.lower().replace(" ", "_")
            if normalized not in _preset_infos_by_name:
                valid = ", ".join(sorted(_preset_infos_by_name.keys()))
                raise KeyError(f"Unknown preset {key!r}; valid: {valid}")
            return _preset_infos_by_name[normalized]
        raise TypeError(f"Preset key must be int, Preset, or str; got {type(key).__name__}")

    def __iter__(self):
        return (_preset_infos_by_id[i] for i in range(SPU94_PRESET__COUNT))

    def __len__(self):
        return SPU94_PRESET__COUNT

    def keys(self):
        """Return the canonical lowercase-underscore preset names (for --list-presets)."""
        return sorted(_preset_infos_by_name.keys(), key=lambda k: _preset_infos_by_name[k].id)


presets = _PresetTable()

    assert P.SPACE_ECHO.value == 7
    assert P.ECHO.value       == 8
    assert P.DELAY.value      == 9

def test_presets_len_10(spu94_module):
    assert len(spu94_module.presets) == 10

def test_presets_string_and_enum_agree(spu94_module):
    by_str = spu94_module.presets["hall"]
    by_enum = spu94_module.presets[spu94_module.Preset.HALL]
    by_int = spu94_module.presets[5]
    by_upper = spu94_module.presets["Hall"]
    assert by_str == by_enum == by_int == by_upper
    assert by_str.id == 5
    assert by_str.name == "Hall"

def test_preset_has_35_reg_values(spu94_module):
    hall = spu94_module.presets["hall"]
    assert len(hall.regs) == 35
    for v in hall.regs:
        assert -32768 <= v <= 32767

def test_iteration_yields_10_presetinfo_in_order(spu94_module):
    infos = list(spu94_module.presets)
    assert len(infos) == 10
    for i, info in enumerate(infos):
        assert info.id == i

def test_off_preset_has_all_zero_gains(spu94_module):
    """Off preset is silent — Phase 5 Plan 03 test_preset_nonzero_tail proved
    this behaviorally. Sanity: its vIIR, vCOMB1..4, vWALL, vAPF1/2, vLIN, vRIN
    should all be 0 (zero gain)."""
    off = spu94_module.presets["off"]
    v_gain_regs = [
        spu94_module.Register.vIIR,
        spu94_module.Register.vCOMB1, spu94_module.Register.vCOMB2,
        spu94_module.Register.vCOMB3, spu94_module.Register.vCOMB4,
        spu94_module.Register.vWALL,
        spu94_module.Register.vAPF1, spu94_module.Register.vAPF2,
        spu94_module.Register.vLIN, spu94_module.Register.vRIN,
    ]
    for reg in v_gain_regs:
        assert off.regs[int(reg)] == 0, (
            f"Off preset {reg.name} should be 0, got {off.regs[int(reg)]}"
        )

def test_preset_matches_snapshot_after_load(spu94_module):
    """Behavioral witness: load a preset into a fresh state, snapshot, and
    the snapshot MUST equal presets[Preset.X].regs element-wise. This is the
    link between the .rodata table and what load_preset actually writes."""
    lib = spu94_module._lib
    size = lib.spu94_state_size()
    state_buf = (ctypes.c_uint8 * 16384)()
    work_buf  = (ctypes.c_uint8 * 8192)()
    state = lib.spu94_init(state_buf, 16384, work_buf, 8192)
    assert state, "spu94_init returned NULL"
    try:
        rc = lib.spu94_load_preset(state, int(spu94_module.Preset.HALL))
        assert rc == spu94_module.SPU94_OK
        # Apply pending writes by ticking once — spu94_load_preset leaves
        # TICK_LATCHED (address/delay) registers pending per Phase 5 D-08.
        lib.spu94_tick(state)
        # Snapshot all 35 registers.
        out = (ctypes.c_int16 * 35)()
        lib.spu94_snapshot_registers(state, out)
        snapshot = tuple(out[i] for i in range(35))
        # Compare to presets[Preset.HALL].regs — must be element-wise equal.
        expected = spu94_module.presets[spu94_module.Preset.HALL].regs
        assert snapshot == expected, (
            f"Hall snapshot != presets[HALL].regs; "
            f"diffs at indices {[i for i in range(35) if snapshot[i] != expected[i]]}"
        )
    finally:
        lib.spu94_destroy(state)
