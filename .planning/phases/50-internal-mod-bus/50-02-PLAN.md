<objective>
Internal mod bus GUI controls in the sampler window

Purpose: Give the user three labeled depth knobs to control how much the global noise modulates pitch, volume, and pan on the active voice. This is a dedicated "Mod Bus" section following the same visual pattern as the Tremolo, Auto-Pan, AM, and Phase Mod sections. Unlike the sweep-based effects, the mod bus has no mutual exclusion -- it can be active alongside any other effect.

Output: "Mod Bus" section label + three rotary knobs (Pitch Depth, Vol Depth, Pan Depth) ranging 0-100% each, wired to PluginProcessor atomics, laid out in the sampler panel after the Phase Mod section.
