    IMPLEMENTATION in PluginProcessor.cpp:

    startRecording():
    - Calculate maxPcmSamples: at 44100 Hz (this phase), max ADPCM blocks = SPU94_SPU_RAM_BYTES / SPU94_ADPCM_BLOCK_BYTES = 32768 blocks. Max PCM samples = 32768 * 28 = 917504.
    - Pre-allocate recordStagingBuffer with reserve(maxPcmSamples), then resize(maxPcmSamples) and zero. This allocation happens on the message thread — safe.
    - Reset recordStagingCount = 0, recordBytesUsed = 0, inputPeakLevel = 0.0f.
    - Set recordingState = REC_RECORDING with memory_order_release.

    stopRecording():
    - Set recordingState = REC_STOPPED with memory_order_release. The audio thread will see this and stop writing.
    - Set recordingJustStopped = true. The GUI timer will call encodeRecordedSample on the message thread.

    encodeRecordedSample():
    - Only callable when recordingState == REC_STOPPED (guard at top).
    - Read recordStagingCount (safe — audio thread has stopped writing).
    - If count == 0, reset state to IDLE and return.
    - Call spu94_sample_encode_to_ram(recordStagingBuffer.data(), recordStagingCount, mixer->voice_ram, 0, SPU94_SPU_RAM_BYTES, loopModeEnabled ? 1 : 0).
    - If bytes > 0:
      - Set voiceSampleBytes = bytes, ramUsed = bytes.
      - Build adpcmStateCache by decoding each block (same loop as loadVoiceSample lines 1978-1984).
      - Copy decoded PCM into waveformData: decode all blocks into a temporary vector, assign to waveformData, set waveformFrames.
      - Set pendingMixerEnable = true.
      - Set voiceSampleName = "Recording".
      - Set voiceSampleLoaded = true with memory_order_release.
    - Set recordingState = REC_IDLE.
    - Free staging buffer memory: recordStagingBuffer.clear(); recordStagingBuffer.shrink_to_fit().

    processBlock standalone path — RECORDING CAPTURE (insert at line ~710, right after the isStandalone check, BEFORE the pendingMixerEnable block):
    - Load recordingState with memory_order_acquire.
    - If REC_RECORDING:
      - Read input from buffer: const float* inL = buffer.getReadPointer(0); const float* inR = (buffer.getNumChannels() > 1) ? buffer.getReadPointer(1) : inL.
      - For each sample i in 0..n-1:
        - Mono-sum: float mono = (inL[i] + inR[i]) * 0.5f.
        - Track peak: peak = max(peak, fabsf(mono)).
        - Convert to int16: clamp mono * 32768.0f to [-32768, 32767], cast to int16_t.
        - Write to recordStagingBuffer[recordStagingCount] if recordStagingCount < recordStagingCapacity.
        - Increment recordStagingCount.
      - Update inputPeakLevel.store(peak, memory_order_relaxed).
      - Update recordBytesUsed: estimated bytes = ((recordStagingCount + 27) / 28) * 16. Store with memory_order_relaxed.
      - Auto-stop check: if recordStagingCount >= recordStagingCapacity, set recordingState = REC_STOPPED, set recordingJustStopped = true (per REC-02).
    - Else (not recording but want input peak for GUI meter display):
      - Still compute peak of input for the level meter (so it shows signal even when idle).
      - Read input float channels, compute peak of mono-sum, store to inputPeakLevel.

    IMPORTANT — the input tap MUST be BEFORE any processing modifies the buffer. The standalone path
    does not modify the float buffer (it reads WavSource int16 data independently), so reading
    buffer.getReadPointer is safe at any point in the standalone block.

    Prevent loadVoiceSample while recording: add a guard at the top of loadVoiceSample():
    if (recordingState.load(memory_order_acquire) != REC_IDLE) return;

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| audio thread -> staging buffer | untrusted input samples cross from host audio callback into recording buffer |
| message thread -> voice_ram | encoded ADPCM crosses from message-thread encoder into shared voice_ram |

| T-56-02 | Denial | audio thread blocking | mitigate | no allocation, no locks, no syscalls on audio thread during recording; only array writes and atomic stores |
