    TIMER CALLBACK (timerCallback, add a new section BEFORE the existing voiceSampleLoaded polling):

    1. Encode-on-stop trigger:
       if (processorRef.getRecordingJustStopped().exchange(false, std::memory_order_acquire)):
         - Call processorRef.encodeRecordedSample() — this runs on the message thread (timer fires on message thread)
         - Reset recordButton text and colour to "Record" / default after encode completes

    2. Record button visual state (every tick):
       - If processorRef.isRecording():
         - Set recordButton text to "Stop" and colour to coral (0xFFE06060)
         - Disable loadSampleButton (setEnabled(false)) to prevent file load during recording
       - Else:
         - Set recordButton text to "Record" and colour to default
         - Enable loadSampleButton (setEnabled(true))

    3. Input peak meter update (every tick, regardless of recording state):
       - Read peak = processorRef.getInputPeakLevel().load(memory_order_relaxed)
       - Convert to dB: dB = (peak > 0.0f) ? 20.0f * log10f(peak) : -60.0f. Clamp to -60..0.
       - Build a text bar: compute barLen = (int)((dB + 60.0f) / 60.0f * 12.0f), clamp 0..12.
         Create bar string of barLen '|' characters.
       - Set inputPeakMeterLabel text: "In: " + bar + " " + dB formatted to 1 decimal + " dB"
       - If peak > 0.95f, set label text colour to coral (clip warning). Else set to grey.

    4. Recording stats update (only when recording):
       - If processorRef.isRecording():
         - Read bytesUsed = processorRef.getRecordBytesUsed().load(memory_order_relaxed)
         - Compute secondsRecorded: samplesRecorded = (bytesUsed / 16) * 28. seconds = samplesRecorded / 44100.0.
         - Compute timeRemaining: totalBytes = SPU94_SPU_RAM_BYTES (0x80000 = 524288). remainBytes = totalBytes - bytesUsed.
           remainSamples = (remainBytes / 16) * 28. remainSeconds = remainSamples / 44100.0.
         - Format: "Rec: " + seconds(1 decimal) + "s / " + remainSeconds(1 decimal) + "s left"
         - Set recordStatsLabel text
       - Else:
         - Clear recordStatsLabel text to ""

    5. RAM meter update during recording:
       - When recording, update ramMeterLabel with live bytesUsed: float kb = bytesUsed / 1024.0f.
         Text: kb(1 decimal) + " / 512 KB"
       - The existing ramMeterLabel update (line ~1185) only fires when voiceSampleLoaded is true.
         Add an additional branch: if processorRef.isRecording(), update ramMeterLabel from recordBytesUsed.
