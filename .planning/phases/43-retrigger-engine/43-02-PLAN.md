<objective>
Add independent L/R retrigger rate configuration and KON-based retrigger phase reset, completing the retrigger engine foundation that downstream effects (tremolo, auto-pan, AM synthesis) will build on.

Purpose: Independent L/R rates enable polyrhythmic modulation -- the left channel oscillating at one speed while the right channel oscillates at another. KON reset ensures every new note starts from a deterministic retrigger state, preventing artifacts from stale oscillation phase.

Output: Updated sweep struct with start_direction for reset, updated voice key_on with retrigger reset, new mixer API for retrigger configuration, and tests covering independent rates and KON behavior.
</objective>
