    1. SPU-94 Beta -- header with one-line description ("Bit-faithful PS1 SPU reverb plugin for your DAW").

    2. Supported Formats and Platforms -- table: VST3 (Linux/macOS/Windows), AU (macOS), LV2 (Linux), CLAP (Linux/macOS/Windows). Note: standalone build is an internal dev tool and is not included.

    3. Installation -- subsections for each OS:
       - macOS: .pkg installer places AU in /Library/Audio/Plug-Ins/Components/, VST3 in /Library/Audio/Plug-Ins/VST3/, CLAP in /Library/Audio/Plug-Ins/CLAP/. Alternative: .dmg drag-install with the same target paths. AU MUST go to the system path (not ~/Library) per PITFALLS-v1.7.md B4 -- Logic ignores user-path AU in some configs.
       - Windows: Run the Inno Setup installer. VST3 goes to C:\Program Files\Common Files\VST3\, CLAP goes to C:\Program Files\Common Files\CLAP\.
       - Linux: Extract tarball, run install.sh. Places VST3 in ~/.vst3/, LV2 in ~/.lv2/, CLAP in ~/.clap/.

    4. Bypassing Unsigned Binary Warnings (PLUG-47):
       - macOS Gatekeeper: Right-click the .pkg or plugin bundle, select Open, then confirm "Open" in the dialog. Alternatively, after first blocked attempt go to System Settings, Privacy and Security, scroll to the blocked app, click "Open Anyway". For .dmg drag-install bundles, run xattr -cr on each plugin bundle after copying (provide the exact xattr -cr commands for each bundle path).
       - Windows SmartScreen: When the "Windows protected your PC" dialog appears, click "More info" then "Run anyway". This is a one-time approval per installer executable.

    5. Resetting Plugin Cache (PLUG-46) -- per-DAW instructions drawn from PITFALLS-v1.7.md B3 table, covering exactly the 6 DAWs from the D-01 test matrix:
       - Reaper: Preferences, VST, "Clear cache and re-scan VST paths for all plugins"; or delete reaper-vstplugins64.ini / reaper-auplugins64.ini / reaper-clapplugins64.ini / reaper-lv2plugins64.ini under the resource path.
       - Ardour: Window, Plugin Manager, click "Re-scan" at bottom.
       - Logic Pro: Settings, Plug-In Manager, "Full Audio Unit Reset". Also delete ~/Library/Caches/AudioUnitCache/com.apple.audiounits.cache and the sandboxed variant.
       - Ableton Live: Preferences, Plug-Ins, Alt+click Rescan for full rescan.
       - FL Studio: Options, Manage plugins, "Rescan and verify installed plugins" with the "Rescan previously verified plugins" checkbox.
       - Bitwig: Dashboard, Settings, Locations, Rescan.

    6. Pro Tools Note -- per D-02, mention that SPU-94 does not ship in AAX format. Pro Tools users can load the VST3 via a wrapper host like Blue Cat PatchWork.

    7. Known Issues -- mention the standalone JUCE volume bug (macOS system volume changes on launch/close of the standalone; does not affect plugin formats). Mention the LV2/Ardour GUI state bug (parameter display may reset when plugin window is closed and reopened; audio processing is unaffected).

    8. Feedback -- ask testers to report: DAW name and version, OS and version, plugin format used, steps to reproduce any issue.

    Do NOT include installation paths that differ from the standard scan paths listed above. Do NOT reference code signing -- it is explicitly deferred.
