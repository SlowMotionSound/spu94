<objective>
Expose the full signed volume range (-0x4000..+0x3FFF) through the C core API and verify
that negative volume produces sample-accurate phase inversion. Add the VxOUTX (outx) storage
field so Phase 35 PMON can read the post-ADSR, pre-volume value.

Purpose: The PS1 SPU volume registers are signed -- negative values flip waveform polarity,
enabling surround encoding, stereo widening, and cancellation effects. The C core math
(q15_mul_truncate) already handles signed values correctly, but the API documentation and
header comments claim unsigned semantics, and the outx storage point needed for PMON does
not exist yet.

Output: Updated voice header with outx field and signed-volume docs, updated voice tick
storing outx, and regression tests proving phase inversion and outx capture.
</objective>
