<objective>
Add per-voice Volume L/R knobs to the standalone sampler GUI that expose the full signed
range (-0x4000..+0x3FFF = -16384..+16383) with a visible phase-flip indicator. Wire the
knobs into the GUI trigger path so the sampler window can play phase-inverted voices.

Purpose: SVOL-05 requires the GUI to expose signed volume. SVOL-02 requires auditing call
sites -- the GUI trigger path currently hardcodes 0x7FFF for both channels, preventing any
volume control or phase inversion from the sampler window.

Output: Two rotary knobs in the sampler panel with a teal-colored "INV" label that appears
when the volume is negative. GUI trigger sends the knob values instead of hardcoded 0x7FFF.
</objective>
