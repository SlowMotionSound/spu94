# Phase 51 Plan 01: GUI Integration & Verification

## Objective

Verify that all v1.10.0 Voice Dynamics & Stereo Effects features coexist cleanly in the sampler window, pass all safety gates, and preserve existing v1.9 functionality.

## Context

This is the final gate for v1.10.0. All 8 effect phases (43-50) have been implemented:
- Phase 43: Retrigger Engine (auto-reversing VCA ramp foundation)
- Phase 44: Tremolo (synchronized L/R volume oscillation)
- Phase 45: Auto-Pan (opposition-phase stereo movement)
- Phase 46: Sidechain Duck (KON-triggered volume drop with recovery)
- Phase 47: Stereo Widener (L/R divergence with mono-safety)
- Phase 48: AM Synthesis (audio-rate retrigger for metallic sidebands)
- Phase 49: Phase Modulator (polarity-cycling sweep)
- Phase 50: Internal Mod Bus (noise-to-pitch/vol/pan routing)

## Tasks

### Task 1: Build Verification (type="auto")

Build the full project in Release mode. Confirm 0 errors, 0 warnings related to v1.10.0 code.

**Done criteria:** All targets build at 100%, including Standalone, VST3, LV2, CLAP.

### Task 2: Unit Test Suite (type="auto")

Run voice/sweep tests (35 tests) and voice_tick tests (63 tests). Confirm 0 failures, 0 regressions.

**Done criteria:** 98+ tests pass with 0 failures across both suites.

### Task 3: RT-Safety Gates (type="auto")

Run the 6 rt_safety labeled tests: no heap, no locks, no syscalls, hotpath alloc gate, negative gate, bench latency.

**Done criteria:** 6/6 pass.

### Task 4: VCA Ramp Accessibility (type="auto")

Verify existing v1.9 VCA ramp controls (ARM button, direction toggle, speed knob, curve toggle) remain accessible and functional in the sampler GUI.

**Done criteria:** All 4 VCA ramp controls present in PluginEditor.cpp with addAndMakeVisible and proper layout coordinates.

### Task 5: Mutual Exclusion Logic (type="auto")

Verify correct mutual exclusion between effects:
- Tremolo active: disables auto-pan, AM, phase mod, duck, VCA ramp ARM
- Auto-pan active: disables tremolo, AM, phase mod, duck, VCA ramp ARM
- AM active: disables tremolo, auto-pan, phase mod, VCA ramp ARM
- Phase mod active: disables tremolo, auto-pan, AM, VCA ramp ARM
- Duck active: disables tremolo, auto-pan, AM, phase mod, VCA ramp ARM
- Stereo widener: NO exclusion (coexists with all)
- Mod bus: NO exclusion (coexists with all)

**Done criteria:** All exclusion patterns confirmed in source code callbacks.

### Task 6: Window Dimensions (type="auto")

Verify sampler window height accommodates all 7 effect sections (tremolo, auto-pan, duck, widener, AM, phase mod, mod bus) plus the existing VCA ramp section without cramming.

**Done criteria:** Window height >= 1500px with all sections having clear vertical separation (>= 100px per section).

## Verification

All 6 tasks pass without code changes required.
