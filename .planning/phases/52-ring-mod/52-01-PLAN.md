<objective>
Add bipolar sweep mode to the C core and wire ring mod as a host-layer effect.

Purpose: Ring mod requires the VCA ramp to cross zero into negative volume (phase inversion). Currently the sweep clamps at zero boundaries within a single quadrant. Adding a bipolar flag lets the retrigger logic flip the phase bit at zero crossings, enabling continuous +0x7FFF to -0x7FFF traversal. This replaces the Phase 49 host-layer workaround (negative-only sweep + remapping formula) with a native C core mechanism.

Output: Bipolar sweep in C core, ring mod activation in host layer, Phase 49 phase mod code replaced, comprehensive tests.
</objective>
