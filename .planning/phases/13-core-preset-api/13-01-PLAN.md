Implement a static `parse_hex_u16` helper function (needed by Plan 02's load, but define it now so the file compiles cleanly and the helper is ready). This is a hand-rolled 4-digit hex parser returning `uint16_t` that avoids `strtol` and the `long` keyword entirely. It handles an optional `0x`/`0X` prefix, processes up to 4 hex digits, and returns 0 on invalid input. Per RESEARCH.md Pitfall 2, this avoids grep-guard's `long` ban.

```c
/* Hand-rolled hex parser: avoids strtol (whose return type is 'long',
 * forbidden by grep-guard in core sources).  Handles optional 0x prefix,
 * exactly 1-4 hex digits.  Returns 0 on invalid input. */
static uint16_t parse_hex_u16(const char *s)
{
    if (!s) return 0;
    if (s[0] == '0' && (s[1] == 'x' || s[1] == 'X')) s += 2;
    uint16_t val = 0;
    int digits = 0;
    for (; *s && digits < 4; s++, digits++) {
        uint16_t nibble;
        if (*s >= '0' && *s <= '9')      nibble = (uint16_t)(*s - '0');
        else if (*s >= 'a' && *s <= 'f') nibble = (uint16_t)(*s - 'a' + 10);
        else if (*s >= 'A' && *s <= 'F') nibble = (uint16_t)(*s - 'A' + 10);
        else return 0;
        val = (uint16_t)((val << 4) | nibble);
    }
    return (digits > 0) ? val : 0;
}
```

6. Write blank line separator.

8. Write `# SPU reverb registers (35 values, hex)\n` comment (per D-03).
