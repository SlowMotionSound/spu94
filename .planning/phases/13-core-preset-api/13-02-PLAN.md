```c
static int parse_bool(const char *s)
{
    if (!s) return -1;
    if (s[0] == '1' && (s[1] == '\0' || s[1] == '\n' || s[1] == '\r')) return 1;
    if (s[0] == '0' && (s[1] == '\0' || s[1] == '\n' || s[1] == '\r')) return 0;
    return -1;  /* invalid */
}
```

3. Implement `spu94_preset_load`:

```
spu94_result_t spu94_preset_load(spu94_state *state,
                                 const char *buf, size_t buf_len)
{
    if (!state) return SPU94_INVALID_STATE;
    if (!buf || buf_len == 0) return SPU94_INVALID_ARG;
```

The parser works line-by-line. It does NOT use `strtok` (modifies input; our buf is `const char *`). Instead, scan for newlines manually:

- Maintain `const char *p = buf;` and `const char *end = buf + buf_len;`
- For each line: find `\n` (or end of buffer). Extract line into a local `char line[512]` buffer (truncate if longer).
- Strip trailing `\r` and `\n` from the line copy.
- Skip empty lines (`line[0] == '\0'`).
- Skip comment lines (`line[0] == '#'`).
- Check for section headers: if `strcmp(line, "[registers]") == 0` set `section = SECTION_REGISTERS; continue;` Same for `[mixer]` and `[dac]`.
- Otherwise, find the first `=` in the line. If no `=` found, skip (unknown format, per D-09 tolerance). Split into `key` (before `=`) and `value` (after `=`).

**Dispatch by section:**

**SECTION_NONE** (metadata before any section):
- `strcmp(key, "version") == 0`: parse but don't store (version=1 is the only version; future versions would check here). Just continue.
- `strcmp(key, "name") == 0`: skip (metadata not stored in engine state).
- `strcmp(key, "description") == 0`: skip (metadata not stored in engine state).
- Any other key: silently ignore (D-09).

**SECTION_REGISTERS**:
- Loop `r = 0` to `SPU94_REG__COUNT - 1`. For each, compare `key` against `spu94_reg_name((spu94_reg_t)r)`.
- On match: `uint16_t val = parse_hex_u16(value);`. Then dispatch by type:
  ```c
  if (spu94_reg_type((spu94_reg_t)r) == SPU94_REG_TYPE_I16) {
      (void)spu94_set_reg_i16(state, (spu94_reg_t)r, (int16_t)val);
  } else {
      (void)spu94_set_reg_u16(state, (spu94_reg_t)r, val);
  }
  ```
  Break out of the register loop after match.
- If no register matches, silently ignore the key (D-09).

**SECTION_MIXER**:
- Use a strcmp chain for the 7 known keys:
  ```c
  if (strcmp(key, "input_gain") == 0)
      spu94_set_input_gain(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "dry_fader") == 0)
      spu94_set_dry_fader(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "patina_fader") == 0)
      spu94_set_patina_fader(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "dry_send") == 0)
      spu94_set_dry_send(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "patina_send") == 0)
      spu94_set_patina_send(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "reverb_fader") == 0)
      spu94_set_reverb_fader(state, (int16_t)parse_hex_u16(value));
  else if (strcmp(key, "latency_comp") == 0) {
      int b = parse_bool(value);
      if (b >= 0) spu94_set_latency_comp(state, b);
  }
  /* else: unknown key, silently ignored (D-09) */
  ```

**SECTION_DAC**:
- strcmp chain for 4 known keys:
  ```c
  if (strcmp(key, "dac_enabled") == 0) {
      int b = parse_bool(value); if (b >= 0) spu94_set_dac_enabled(state, b);
  } else if (strcmp(key, "dac_fir_enabled") == 0) {
      int b = parse_bool(value); if (b >= 0) spu94_set_dac_fir_enabled(state, b);
  } else if (strcmp(key, "dac_noise_enabled") == 0) {
      int b = parse_bool(value); if (b >= 0) spu94_set_dac_noise_enabled(state, b);
  } else if (strcmp(key, "dac_true_oversample") == 0) {
      int b = parse_bool(value); if (b >= 0) spu94_set_dac_true_oversample(state, b);
  }
  /* else: unknown key, silently ignored (D-09) */
  ```

Return `SPU94_OK` at end.

**Critical constraints:**
- Do NOT reset state before parsing. Per D-08, missing keys retain engine defaults. The caller calls `spu94_reset()` first if they want a clean slate (per RESEARCH.md Pitfall 5).
- Do NOT fail on malformed lines -- skip them. Only NULL state or NULL/empty buf are errors.
- No `float`, `double`, `malloc`, `calloc`, `realloc`, `free`, or unqualified `long` anywhere.
- Use the `(void)` cast on `spu94_set_reg_i16` / `spu94_set_reg_u16` return values, matching the pattern from `spu94_presets.c`.
- The `parse_hex_u16` helper handles the `0x` prefix and returns `uint16_t` -- validation of range is implicit since `uint16_t` cannot exceed 0xFFFF. For values hand-edited beyond 4 digits, `parse_hex_u16` naturally takes only the first 4 digits after the prefix.
