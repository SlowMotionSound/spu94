<objective>
Add a selectable waveform shape (Triangle / Saw Down / Saw Up) to the VCA ramp sweep state machine. Triangle is the existing auto-reverse behavior. Sawtooth shapes reset level to start instead of reversing direction at boundaries, producing classic sawtooth LFO patterns. Wire shape through the API and host layer so all four VCA ramp effects (tremolo, AM, ring mod, auto-pan) can use any shape.

Purpose: Exposes the full set of native SPU sweep waveforms as a user-selectable parameter, tripling the timbral variety of all modulation effects from 2 waveforms (linear/exp triangle only) to 6 (3 shapes x 2 curves).

Output: Working shape parameter end-to-end from C core through host layer, with tests proving all three shapes in both curve modes.
</objective>

if (sw->retrigger_enable) {
    int16_t boundary;
    if (effective_phase == 0) {
        boundary = (sw->direction == 0) ? 0x7FFF : 0;
    } else {
        boundary = (sw->direction == 0) ? -0x7FFF : 0;
    }
    if (sw->level == boundary) {
        if (sw->bipolar && boundary == 0) {
            sw->direction ^= 1;
            sw->phase ^= 1;
        } else {
            sw->direction ^= 1;
        }
        sw->counter = 0;
    }
}
