## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Audible-range phase without GUI surface to reach it | Phase 23's planner deferred the standalone slider widen to Phase 24, which left the +24 dB drive range unreachable from any UI. Discovered during UAT when Anthony first swept past 1.0 and heard the int16 wrap evaporate the signal. | advisory | When a phase touches an *audible* parameter range, the GUI surface that exposes that range is part of the UAT contract. Either include the slider widen in-phase or write the SPEC/PLAN with an explicit "no audible UAT in this phase" gate so the testability gap is visible up front. |
| Float -> int16_t cast with no upstream clamp | Same shape of bug bit us in v1.5 register shadows (`e2e8f57`) and again in Phase 23 Plan 02's first revision: `static_cast<int16_t>(atomic * 0x7FFF)` wraps when atomic > 1.0. Audible: quieter past unity, then silent. | advisory | Any cast `float -> int16_t` with values that can exceed +/-32767 must clamp first (boundary::toInt16 does this correctly) or use a wider integer type. Flag at design-review time on any new register/parameter wiring. |
