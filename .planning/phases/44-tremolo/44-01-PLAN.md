- Counter-accumulate math: increment = 0x8000 >> max(0, shift - 11). Step fires when counter bit 15 set.

    Create src/spu94/spu94_tremolo.c with:

    hz_to_shift implementation: Build a lookup table of (shift, step) pairs and their corresponding Hz values. For each shift 0-17 and step 0-3, compute the Hz rate. Formula: at 44100 Hz sample rate, for linear mode decrease with step_index S and shift SH:
    - ticks_per_step_fire = max(1, 1 << max(0, SH - 11))
    - step_magnitude = (8 - S) << max(0, 11 - SH) [capped at minimum 1 when shift > 11]
    - half_cycle_ticks = (0x7FFF / step_magnitude) * ticks_per_step_fire
    - hz = 44100.0f / (2.0f * half_cycle_ticks)
    Find the (shift, step) pair whose Hz is closest to the requested Hz. Clamp output shift to 0-31.

    tremolo_configure implementation: Call spu94_voice_mixer_set_sweep_l and spu94_voice_mixer_set_sweep_r on the given voice with retrigger_enable=1, direction=1 (decrease -- starts from current level and ramps down, then auto-reverses up), phase=0 (positive quadrant). For ratio: L gets the base shift/step directly. R gets a shift adjusted by the ratio -- if ratio_num/ratio_den > 1, R shift decreases (faster); if < 1, R shift increases (slower). The adjustment: find the shift/step for (hz * ratio_num / ratio_den) using hz_to_shift, where hz is derived back from the given shift/step. Simpler approach: R_shift = shift - log2(ratio_num/ratio_den) rounded, clamped 0-31.

    apply_depth implementation: Pure integer math, RT-safe. The sweep oscillates between 0 and 0x7FFF. Depth determines how much of that oscillation affects the output volume.
    - modulation = ((int32_t)(0x7FFF - sweep_level) * depth) / 255
    - output = base_vol - (int16_t)((int32_t)base_vol * modulation / 0x7FFF)
    - Clamp output to 0..0x7FFF range.

    When sweep_level = 0x7FFF (peak): modulation = 0, output = base_vol (no attenuation).
    When sweep_level = 0 (trough): modulation = 0x7FFF * depth / 255, output = base_vol * (1 - depth/255).
    When depth = 0: modulation = 0 regardless of sweep_level, output = base_vol always.
