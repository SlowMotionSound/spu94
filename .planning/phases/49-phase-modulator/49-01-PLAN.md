<objective>
Phase modulator DSP activation: polarity-cycling sweep configuration and zero-crossing depth formula

Purpose: Create a unique SPU-94 timbral effect by oscillating volume through zero into negative polarity. Unlike tremolo (which stays positive), the phase modulator crosses zero, causing signal inversion when negative. At slow rates this breathes/widens stereo; at medium rates the repeated cancellation/reinforcement creates hollow phasey character. The zero-crossing moment is the key unknown -- PMOD-04 requires prototyping and documenting whether it clicks, pops, or transitions smoothly.

Output: Phase mod atomics in PluginProcessor.h, activation block + depth formula + mutual exclusion in PluginProcessor.cpp, integration test in test_sweep.c, ADR documenting zero-crossing findings
</objective>

  In PluginProcessor.cpp, add a "Phase Modulator" block after the AM block in processBlock:

  ACTIVATION LOGIC (per PMOD-01, PMOD-02):
  - Mutual exclusion check: if tremolo OR autoPan OR AM is active, treat phaseMod as disabled (lowest priority, same tier as AM -- they share the retrigger hardware)
  - On enable (phaseModEn and not phaseModWasActive): configure both L and R sweeps with:
      mode=0 (linear -- simplest zero-crossing behavior for prototype)
      direction=0 (increase -- in negative phase this means moving TOWARD -0x7FFF)
      phase=1 (negative -- enables oscillation between 0 and -0x7FFF)
      shift/step from hzToShift() (reuses the existing tremolo Hz table -- same rate range)
      retrigger_enable=1
    IMPORTANT: After configuring, set the sweep level to 0 explicitly. The sweep will start at 0, go to -0x7FFF, retrigger back to 0, and repeat. The depth formula maps this 0..-0x7FFF oscillation into the +0x7FFF..-0x7FFF effective volume range.
  - On parameter change (phaseModEn and phaseModWasActive): reconfigure if hz changed.
  - On disable (not phaseModEn and phaseModWasActive): deactivate sweeps, set phaseModWasActive=false.

  DEPTH FORMULA (per PMOD-03) -- this is the KEY difference from tremolo:
  The sweep level oscillates 0 to -0x7FFF (with phase=1, retrigger=1).
  The depth formula translates this into effective volume crossing zero:

    vol = 0x7FFF + (sweep_level * 2 * depth)

  At depth=1.0:
    sweep_level=0     -> vol = +0x7FFF (full positive -- normal signal)
    sweep_level=-0x7FFF -> vol = 0x7FFF + (-0x7FFF * 2 * 1.0) = -0x7FFF (full inversion)
  At depth=0.5:
    sweep_level=0     -> vol = +0x7FFF
    sweep_level=-0x7FFF -> vol = 0x7FFF + (-0x7FFF * 2 * 0.5) = 0 (just touches zero, no inversion)
  At depth=0.25:
    sweep_level=0     -> vol = +0x7FFF
    sweep_level=-0x7FFF -> vol = 0x7FFF + (-0x7FFF * 2 * 0.25) = +0x3FFF (stays positive, just attenuates)

  Apply to both vol_l and vol_r (both channels oscillate together for the prototype).
  Clamp the result to the int16_t range (-0x7FFF to +0x7FFF).
  Clamp depth input 0.0-1.0 at point of use (T-49-01 mitigation, same as AM/tremolo).

  Apply the same mutual exclusion pattern as AM: when any higher-priority effect disables phase mod mid-playback, deactivate sweeps and reset phaseModWasActive.

  ZERO-CROSSING ADR (per PMOD-04):
  Create docs/adr/ADR-0060-phase-modulator-zero-crossing.md documenting:
  - Title: "Phase Modulator Zero-Crossing Behavior"
  - Status: Accepted
  - Context: When the phase modulator depth formula drives volume through zero, the signal instantaneously inverts polarity. This document captures the expected audible behavior.
  - Analysis: The zero crossing is INSTANTANEOUS (single-sample transition from positive to negative volume). There is no interpolation or smoothing. On PS1 hardware, the volume register IS the multiplier applied at sample rate -- if it transitions from +1 to -1 between samples, that sample boundary is a polarity discontinuity.
  - Finding: With linear mode (mode=0), the transition through zero is smooth and continuous because the volume ramp passes through zero gradually (multiple intermediate values). With exponential mode (mode=1), there is a special case: the phase bit is IGNORED for exponential decrease (ADR-0059), which means exponential mode cannot reach negative territory through normal sweep behavior. Therefore the prototype uses LINEAR mode only.
  - Audible prediction: Linear zero-crossing should produce NO click/pop because the volume ramp increments smoothly through zero (each tick changes level by step_magnitude, which at shift=9 is a small fraction of the full range). The crossing takes multiple samples, not a single discontinuity.
  - Recommendation: Ship with linear mode. If users report artifacts at very fast rates, consider adding a 1-sample crossfade at the zero boundary. Label the control as ready (not experimental) given the smooth linear crossing.
  - Decision: Phase modulator uses mode=0 (linear) only. The "exponential ignores phase bit" exception (ADR-0059) makes exponential mode unsuitable for polarity cycling.
