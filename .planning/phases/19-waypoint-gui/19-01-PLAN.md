# Phase 19 Plan 01: Waypoint GUI — Ticks + 17-Position Snap

Surface the 8 user-slot midpoints as visible detents on the morph knob. Ticks render inside the Sony dot ring (visually subordinate to the Sony anchors that remain the perceptual landmarks). Filled vs empty state is colour-coded.

## Rationale

Phase 18 added 8 transparent slots in the C core. The user needs to (a) see they exist as detents, (b) tell at a glance which are filled vs empty, and (c) feel the knob settle into the midpoint positions. This plan is purely visual — interaction (EDIT/SAVE/REVERT) comes in 19-02.

## Design

- Ticks INSIDE the Sony dot ring (tucked between the knob's outer edge and the colored Sony dots) so Sony anchors remain the outer visual landmark and ticks read as "closer to the encoder"
- PS1 blue for filled, dim grey for empty — high contrast at typical viewing distance, fits the existing PS1-controller palette
- Visual-only at this stage; the click-to-edit affordance is added in 19-02
