# Phase 19 Plan 02: Waypoint GUI — Edit Flow + Per-Tick Actions

Make the ticks interactive. Click EDIT on a parked tick to enter Advanced view focused on that slot. SAVE captures the current register state; REVERT clears the slot entirely. EXPORT writes a single-slot file; LOAD stamps any single-slot file onto the parked tick.

This plan completes the user-facing surface for waypoint authoring.

## Major UX Decisions

See `design_decisions` in the frontmatter for the dropdown-vs-buttons resolution, REVERT semantics, drop-anywhere LOAD, and the state-management-above-audio-gate fix.

## Engine State Mirroring Overhaul

A series of audible/visible bugs surfaced during this plan, all rooted in stale or per-engine state:

1. After SAVE, glide away and back → morph engine glided to the GENERIC unedited slot (Sony interp), not the saved waypoint
2. Sliders didn't update without a WAV loaded
3. needShadowSync rewrote engines[0] to the morph target on every Advanced entry, causing an audible blip when engines[0] wasn't already there
4. SAVE could miss freshly-edited m/d-prefix (TICK_LATCHED) registers if snapshot fired before spu94_tick

All four fixes are listed in task 8 and detailed in SUMMARY.
