  1. Add member declarations:
     - juce::Slider stereoWidthSlider -- rotary, 0.0 to 1.0 (displayed as 0-100%), default 0.0
     - juce::Label stereoWidthLabel -- "Width"
     - juce::Label stereoWidthMonoIndicator -- displays estimated mono loss (e.g., "Mono: -0.0 dB" to "Mono: -2.5 dB")

  IMPLEMENTATION (SamplerPanel.cpp):

  2. Constructor: initialize stereo width controls.
     - stereoWidthSlider: setRange(0.0, 1.0, 0.01), setValue(0.0), rotary style, textbox shows percentage (multiply by 100 in stringFromValue)
     - stereoWidthLabel: "Width"
     - stereoWidthMonoIndicator: initially "Mono: 0.0 dB" (no loss at zero width), non-editable label, smaller font, color-coded (green when < 1 dB loss, yellow 1-2 dB, orange 2-3 dB)
     - Add slider listener (this).

  3. resized(): Position the width section in the effects area. One knob + one label + one indicator line below. Section labeled "Stereo Width". Place after the sidechain duck section.

  4. Listener callback:
     - sliderValueChanged: if stereoWidthSlider changed, write value to processor.getStereoWidth().store(value, std::memory_order_relaxed).

  5. timerCallback: update width control and mono indicator:
     - Read processor.getStereoWidth() and update slider if not being dragged.
     - Compute and display mono loss estimate:
       ```
       float width = processor.getStereoWidth().load(std::memory_order_relaxed);
       // Worst-case mono loss (center-panned signal at max volume):
       // offset = width * 0x2000
       // Louder channel clips at 0x3FFF, quieter = 0x3FFF - offset
       // mono_sum_ratio = (0x3FFF + max(0, 0x3FFF - offset)) / (2.0f * 0x3FFF)
       float offset = width * 0x2000;
       float mono_ratio = (0x3FFF + std::max(0.0f, 0x3FFF - offset)) / (2.0f * 0x3FFF);
       float loss_dB = 20.0f * std::log10(std::max(0.001f, mono_ratio));
       // Display: "Mono: -X.X dB" (loss is negative or zero)
       stereoWidthMonoIndicator.setText(
           juce::String::formatted("Mono: %.1f dB", loss_dB), juce::dontSendNotification);
       ```
     - Color-code the indicator label:
       - loss_dB >= -1.0: green (good mono compatibility)
       - loss_dB >= -2.0: yellow (moderate)
       - loss_dB < -2.0: orange/red (approaching mono-safety limit)

  6. The width knob should be always accessible regardless of tremolo/auto-pan state (it coexists with all other effects). No mutual exclusion visual disabling needed.
