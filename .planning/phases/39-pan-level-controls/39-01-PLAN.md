    **updateVoiceVolumes() implementation (new private method):**

    Pan-to-register math per CONTEXT.md decisions:
    1. Read pan = voicePanKnob.getValue() / 100.0 (normalize to -1.0..+1.0)
    2. Read level = voiceLevelKnob.getValue() / 100.0 (normalize to 0.0..1.0)
    3. Compute gain_l and gain_r using linear pan law:
       - gain_l = std::min(1.0, 1.0 - pan)
       - gain_r = std::min(1.0, 1.0 + pan)
       This means: center (pan=0) gives gain_l=gain_r=1.0; hard left (pan=-1) gives gain_l=1.0, gain_r=0.0; hard right (pan=+1) gives gain_l=0.0, gain_r=1.0.
    4. vol_l_raw = static_cast<int16_t>(level * gain_l * 0x3FFF + 0.5)
    5. vol_r_raw = static_cast<int16_t>(level * gain_r * 0x3FFF + 0.5)
    6. Clamp both to 0..0x3FFF range
    7. If voiceInvToggle.getToggleState() is true, negate both: vol_l = -vol_l_raw, vol_r = -vol_r_raw
    8. Call processorRef.setGuiVoiceVolL(vol_l) and processorRef.setGuiVoiceVolR(vol_r)
    9. Set voiceInvIndicator visibility to voiceInvToggle.getToggleState()
