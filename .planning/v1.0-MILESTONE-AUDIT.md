- Accept as known gap and note in MILESTONES.md

### 2. Python `work_buf_size` Default Undersized

`SPU94()` and `api.init()` default to `work_buf_size=8192` bytes. The Hall preset requires at least 11,124 bytes. At 8,192 bytes, all delay-line tap reads above byte 8,192 return 0 silently; writes are discarded. No crash, no error, no warning.

**Impact:**
- `self_test()` uses Hall and does not detect degraded state
- Modulation harness (Phase 7, TEST-05) ran Hall with this degraded buffer — stability results are likely valid (int16 bounds hold) but acoustic character of catalogued modulations may not reflect real Hall behavior

**Fix:** Change default `work_buf_size` to 65536 (64 KB covers all PS1 presets comfortably). One-line change in `reverb.py` and `api.py`. Should be fixed before M1 close-out.
